## 学习路径

### 路径A：自我成长（先管理自己）

```
1. 情绪管理（觉察）
   ↓
2. 情绪管理（保持客观）
   ↓
3. 穿越情绪按钮
   ↓
4. 放下对错标准
   ↓
5. 述情（准确表达感受）
   ↓
6. 共情（理解对方）
```

### 路径B：改善关系（先理解对方）

```
1. 四步共情法（接纳对方情绪）
   ↓
2. 允许（放下控制）
   ↓
3. 影响（以身作则）
   ↓
4. 述情（让对方懂你）
   ↓
5. 自我情绪管理
```

### 路径C：冲突处理

```
1. 觉察自己起情绪（情绪管理第一步）
   ↓
2. 保持客观，不立即反应
   ↓
3. 用四步共情法回应对方
   ↓
4. 用述情句型表达感受
   ↓
5. 允许差异存在
   ↓
6. 找到双赢解决方案
```

## 能力组合矩阵

| 组合 | 效果 | 典型场景 |
|------|------|---------|
| 情绪管理 + 述情 | 情绪稳定+表达清晰 | 重要谈话前准备 |
| 共情 + 允许 | 理解+接纳 | 接纳伴侣的缺点 |
| 影响 + 允许 | 改变+不控制 | 让孩子/伴侣成长 |
| 四步共情 + 六个句型 | 先理解+再表达 | 处理伴侣抱怨 |
| 穿越按钮 + 述情 | 根治+预防 | 处理反复出现的冲突 |

## 情绪管理四步骤

```
1. 觉察
   "我在起情绪了"
   
2. 保持客观
   "这是客观事实还是我的假设？"
   
3. 穿越情绪按钮
   "这种感觉以前有过吗？是童年创伤吗？"
   
4. 放下对错标准
   "我想要对还是想要关系好？"
```

## 述情六个句型

| 句型 | 公式 | 示例 |
|------|------|------|
| 一 | 心情不好+原因 | "我今天心情不好，因为..." |
| 二 | 行为+感受 | "你没接电话，我有点担心" |
| 三 | 需求状态 | "我渴了"（替代"给我倒水"） |
| 四 | 喜欢vs不喜欢 | "我喜欢安静的晚上" |
| 五 | 可以替代命令 | "你可以帮我...吗？" |
| 六 | 我希望替代你应该 | "我希望你..." |
