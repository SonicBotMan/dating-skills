# SKILL: intermittent-reward — 间歇性奖赏机制

> 提取自《谜男方法》第七章
> 忠实于原文，不改造不净化

---

## R 原文引用

> "驯兽师都知道，间歇性提供奖赏比持续奖赏有效多了。同理可证，向目标发出IOI当作奖赏也必须出乎意料才好。方程式里一定要有不确定因素，对方才会觉得比较吸引人，可以体会到希望、怀疑、惊讶、渴望、患得患失等等多种戏剧化的情绪。"

> "所以用IOI奖赏她只是最简单的诠释罢了。其实我们是穿插用间歇性、突然的IOI与IOD奖赏她的投资。这种忽冷忽热、推推拉拉的动力非常能够刺激情绪。当她如此受到奖赏，比较可能追求你，并配合服从性测试。"

## I 方法论骨架

```
间歇性奖赏的核心：不可预测的奖励 > 持续奖励（行为心理学）

┌─────────────────────────────────────────────────────────────┐
│ 奖赏机制                                                     │
├─────────────────────────────────────────────────────────────┤
│ 持续奖赏：每次都给予IOI → 快速失去吸引力                    │
│ 间歇奖赏：不规律给予IOI → 制造不确定感 → 更强追逐动力      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 情绪波动制造                                                 │
├─────────────────────────────────────────────────────────────┤
│ IOI（奖赏）+ IOD（剥夺）→ 不确定感 → 希望+怀疑+惊讶+渴望   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 最佳时机                                                     │
├─────────────────────────────────────────────────────────────┤
│ IOD最佳时机：DHV之后、目标感到强烈吸引力的一刻              │
│ IOI最佳时机：她投资之后、表现好之后                         │
│ 剥夺最佳时机：升高之前（她更可能接受升高）                  │
└─────────────────────────────────────────────────────────────┘
```

## A1 书中案例

**引诱-上钩-收线-释放中的间歇性**（第2799行）：

> 把妹达人[诱惑] → 目标[投资] → 把妹达人[间歇性奖赏]

**A3阶段的剥夺层面**（第2571行）：

> 当她把你拉回去，你要用间歇性IOI奖赏她。而剥夺的最佳时机是在DHV之后、目标感到强烈吸引力的一刻，很有趣吧？这就是她最有可能把你抢回来的时机。同样地，发出IOD的最佳时机是在升高之前，因为这样她最有可能接受升高。例如，你在亲吻她之前转身背对她，她比较可能接受亲吻。

## A2 触发场景 + 语言信号

**触发场景**：
- A3阶段——需要强化她的追逐动力时
- 关系进入平台期——需要制造张力时
- 她过于主动——需要降温时
- 她开始失去兴趣——需要重新吸引时

**IOI/IOD节奏示例**：
- 你讲故事，她听得很开心（她投资）
- 你突然转向别人聊天（IOD）
- 她主动拉你回来（追逐）
- 你给她IOI（奖赏）

**制造情绪波动**：
- 让她好奇（"你怎么知道？"）
- 让她患得患失（不确定你是否喜欢她）
- 让她惊讶（意外的负面评价）
- 让她渴望（突然冷淡让她想追回来）

---

## E 可执行步骤

1. **识别奖赏时机**：她投资/表现好时给予IOI
2. **不规律奖赏**：每隔1-2次配合才给一次IOI
3. **IOD制造剥夺**：在DHV后、升高前使用IOD
4. **观察反应**：她是否开始追逐你？
5. **推拉结合**：IOD后给更大的IOI（推推拉拉）
6. **维持张力**：让她不确定你是否真的喜欢她

---

## B 边界

**适用范围**：
- A2-C阶段——贯穿整个吸引和舒适感过程
- 需要强化对方投资和追逐动力时
- 关系进入无聊/稳定状态时需要制造波动

**不适用**：
- 对方已经明确表示不喜欢你时——不能强行使用
- 长期关系中——需要更真诚的情感交流
- 对方有情感问题/脆弱时——间歇性冷漠可能造成伤害

**关键警告**：
- 间歇性奖赏比持续奖赏更有效，但需要适度
- 过度IOD=让她觉得你真的不喜欢她
- 这是一种操控技术——伦理边界需要明确
- 长期关系中需要真诚而非操控

**猫绳理论的延伸**：
- 诱饵放在可及范围之外
- 让她追逐但又差一点
- 构建"失去的恐惧"和追逐动力
