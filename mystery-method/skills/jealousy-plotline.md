## I 方法论骨架

```
嫉妒情节的本质：制造"她可能会失去你"的危机感，激活她的损失厌恶。

┌─────────────────────────────────────────────────────────────────┐
│ 嫉妒情节机制                                                     │
├─────────────────────────────────────────────────────────────────┤
│ 她看见你被其他女人认可 → 她评估"我要输了"                      │
│ → 损失厌恶激活 → 她追你                                        │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 制造嫉妒的方式                                                   │
├─────────────────────────────────────────────────────────────────┤
│ 1. 枢纽坐在你腿上                                               │
│ 2. 介绍另一个女人给她认识                                       │
│ 3. 提到"我的女朋友..."                                         │
│ 4. 融合组合时让她看到你被其他女人围绕                           │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 关键原则                                                         │
├─────────────────────────────────────────────────────────────────┤
│ 行动展示 > 口头暗示                                             │
│ 让她"发现"比告诉她更有效                                       │
│ 嫉妒情节必须在C1-C2阶段                                         │
└─────────────────────────────────────────────────────────────────┘
```

## A1 书中案例

**C1阶段的嫉妒展示**（第3227行）：

> 想想你们在舒适感阶段，你并没有勾引她，只是在C1阶段一起说笑，然后另一个女人过来坐在你大腿上。你介绍两女认识，然后"轰"的一下，情绪马上就变了！现在目标知道她其实喜欢你。

**10分美女的嫉妒情节**（第3257行）：

> 如果你希望只针对10分美女进攻，记住你必须实行高级团体理论：融合团体的艺术。当我在组合里选定10分为目标，并且施展嫉妒情节之后，总是比较容易成功。让你的目标嫉妒必须是C1或C2阶段的必要部分，然后她们就会想要你。

**口头制造嫉妒**（第3259行）：

> 无论你有没有女友，都要提到你已经有女友了："我的一个女朋友……"或"我女友会不爽你跟我搞暧昧。"

## A2 触发场景 + 语言信号

**触发场景**：
- C1-C2阶段：需要强化她的感情时
- 她还不够主动追你时
- 友谊区边缘需要激活时
- 10分高分目标需要更强吸引时

**嫉妒情节信号**：
- 她突然对你更关注
- 她开始问你"那是谁"
- 她的态度变热
- 她开始主动

**需要嫉妒的情况**：
- 她表现冷淡
- 她把你当朋友
- 她的IOI不够强
- 她的价值评估不够高

---

## E 可执行步骤

1. **找枢纽帮忙**：让她坐你腿上或跟你互动
2. **融合组合**：打开新组合然后介绍给她
3. **直接开口**：问"你喜欢某个女孩，你能不能帮我让她嫉妒一下"
4. **提到女朋友**：说"我女友会不爽..."看她反应
5. **假装接电话**：说有电话进来，显示你很有行情
6. **让她自己发现**：最好的嫉妒是她"碰巧"看到
7. **之后给IOI**：她表现出嫉妒后，给她兴趣指标奖赏

---

## B 边界

**适用范围**：
- C1-C2阶段建立更深的感情
- 她还不够主动时
- 友谊区需要激活时
- 高分目标需要更强吸引时

**不适用**：
- A1-A2阶段——她还不需要嫉妒你
- S阶段——已经不需要嫉妒情节
- 她已经非常主动时——嫉妒可能多余
- 真的女朋友在场时——会搞砸

**关键警告**：
- 嫉妒情节是制造危机感，不是真的威胁她
- 不能真的让她觉得你没兴趣了
- 必须是轻微的嫉妒，不能太过分
- 之后要给她IOI，否则她会觉得真的输了
