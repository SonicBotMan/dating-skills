## I 方法论骨架

```
求爱流程严格遵循 A(吸引) → C(舒适感) → S(诱惑) 三阶段顺序，不可颠倒、不可跳过。

┌─────────────────────────────────────────────────────────────┐
│ 阶段A：吸引 (Attract)                                       │
│   A1 打开组合 → A2 女对男的兴趣 → A3 男对女的兴趣          │
│ 阶段C：舒适感 (Build Comfort)                               │
│   C1 对话 → C2 联系感 → C3 亲密感                          │
│ 阶段S：诱惑 (Seduce)                                        │
│   S1 前戏 → S2 LMR(最后一刻抵抗) → S3 性交                 │
└─────────────────────────────────────────────────────────────┘

总时长：4-10小时（平均7小时）
分布：吸引(短) + 舒适感(长) + 诱惑(短)
```

**M3顺序四个错误**：
1. 先诱惑(S→...)：愚人的笨招 → 触发ASD被打枪
2. 先舒适感(C→S)：好好先生 → 困在友谊区/防护罩
3. 跳过舒适感(A→S)：玩家陷阱 → 事后反悔(Buyer's Remorse)
4. 只有吸引(A→C)：友谊区 → 无法升高

## A1 书中案例

**Jim与Jannie的"事后反悔"案例**（第957-997行）：

吉姆和珍妮互相吸引，当晚调情火热，但无法转移阵地于是交换电话。隔天吉姆打电话，珍妮态度冷淡，不回电。

女方视角：珍妮确实想再见面，但吉姆没有足够停留在舒适感阶段。隔天她不在当晚的情绪兴奋状态，文化制约让她觉得跟不太熟的人做出那些事有点愧疚。

**结论**：吉姆没有花足够时间停留在"舒适"阶段，导致珍妮"事后反悔"。这是典型的跳过舒适感直接诱惑的失败模式。

## A2 触发场景 + 语言信号

**触发场景**：
- 你刚搭讪认识一个女生，想知道接下来该怎么推进
- 你不确定是否应该直接约她上床
- 你发现自己经常被发好人卡或进入友谊区
- 你想知道为什么每次约会都很顺利但最后她冷淡了

**语言信号**：
- "我们太快了吗？"、"你是不是对每个人都这样？"、"你只是想上床吧？" → 舒适感不足
- "我觉得我们还是做朋友吧" → 困在友谊区
- "你人真的很好，但是..." → 防护罩模式

## E 可执行步骤

1. **诊断当前位置**：你现在处于A/C/S哪一阶段？她的IOI强度如何？
2. **检查阶段顺序**：你是否在某阶段停留足够时间？
3. **计算时间投入**：累计相处时长是否达到七小时法则？
4. **识别失败模式**：对照四个错误模型，找出你当前的问题
5. **回归正确阶段**：如果跳阶段，从对应阶段重新开始
6. **规划时间分配**：A阶段(短)→C阶段(长)→S阶段(短)，总计4-10小时

## B 边界

**适用范围**：
- 从认识到性关系的完整求爱流程
- 线下社交场合（夜店、酒吧、派对、社交活动）
- 需要系统化流程指导的初学者

**不适用**：
- 线上社交媒体/约会App场景（本书写于2007年，Tinder出现前）
- 已经建立长期关系的伴侣（需要的是关系经营而非游戏流程）
- 当对方明确表示不感兴趣且无IOI反馈时（尊重边界）

**核心前提**：
- 女性有预设的吸引力开关，吸引是情不自禁的
- 高价值不是靠追，而是靠展示
- 求爱可以被系统化、流程化、可训练化

**伦理边界**（批判性识别）：
- 本框架将女性描述为"目标"和"电路接收器"，忽视了女性的主体性
- "绕过ASD"、"摧毁LMR"等技术实质上是绕过对方真实意愿
- 把操控当技巧、把感情当游戏，是本方法论的核心伦理问题
