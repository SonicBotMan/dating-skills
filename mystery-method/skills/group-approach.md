## R 原文引用

> "好好先生通常会等候女人落单时跟她独处，然后追求她。但是谜男方法的策略是直接进攻团体，因为女人很容易在社交情境中被价值最高的男人吸引。"

> "女人聚在一起时，就会进入团体思考的心态。用相同的心理机制来预选：对于自己的选择和感受，会互相寻求认同。"

> "当你拥有一定程度的社交认证，打开组合将变得轻而易举。因此，一开始选择组合时，千万别太挑剔，宁可先混入任何组合中，也不要太挑剔而落得形单影只，丧失征服整个现场的机会。"

## I 方法论骨架

```
群组打开的核心逻辑：直接进攻团体，通过DHV和否定接管整个团体，而非等待目标落单。

目标类型处理：
┌─────────────────────────────────────────────────────────────┐
│ 双人组（目标+障碍）                                          │
│   → 先赢得障碍者支持                                        │
│   → 故意忽视目标                                            │
│   → 否定目标 + 向障碍者展示高价值                            │
│   → 障碍者接纳后，焦点转向目标                               │
├─────────────────────────────────────────────────────────────┤
│ 三人+组合                                                    │
│   → 解除所有障碍武装                                        │
│   → 隔离目标（请求许可或直接带离）                          │
│   → 持续进挪测试                                            │
└─────────────────────────────────────────────────────────────┘

打开成功标志（达到上钩点）：
- 她开始对你的笑话发笑（即使不好笑）
- 她转身面对你
- 她触摸你
- 她询问你的名字
```

## A1 书中案例

**中式餐馆"外面打架的女人"间接开场白**（第1227-1231行）：

谜男和搭档走进中式餐馆，看见两个女大学生。

> 谜男：喔，我的天啊，你们有没有看到在外面打架的女人？
> 美女：（在她们开口之前，你打断她们）
> 谜男：她们为了一个男的打架，后来我跟他讲过话，他叫做葛伦，有够扫兴的名字，葛伦耶！她们互抓对方的头发，有个女人的假奶还掉了出来。我看过的胸部很多，但是那真是"下垂的布袋奶"……你知道的，一周刊的术语。

**操作要点**：间接开场白——不显露意图，用一个有趣的话题取得团体注意力，让目标不知道你是来把她的，从而解除防护罩。结果：她们消失在餐馆里，两人跟进去继续互动。

## A2 触发场景 + 语言信号

**触发场景**：
- 夜店、酒吧、派对、餐厅等社交场合
- 目标在2人以上的团体中
- 目标看起来有防护罩（回避、冷淡、跟朋友黏在一起）

**语言信号**：
- 目标问"你谁啊？"、"你想干什么？" → 防护罩激活，需要先解除
- 目标的朋友问"你们认识吗？" → 需要先赢得障碍者
- 目标转头看你、对你笑、主动找你说话 → 上钩点到达

**标准开场白类型**：
- 间接开场（不提意图）："你们有没有看到外面打架的女人？"
- 直接开场（用于单人组）："我想知道你除了外在美，还有没有内涵"
- 假性时间限制："我只能待一下，我跟朋友来的"

## E 可执行步骤

1. **三秒法则**：进入现场后3秒内必须开始搭讪，不能犹豫
2. **选择组合**：别太挑剔，先混入任何组合建立社交认证
3. **识别组合类型**：双人组/三人+/单人组 → 调整策略
4. **执行开场白**：使用间接开场白（团体）或直接开场白（单人）
5. **三分钟例外**：若3分钟内会有外力干扰，等待合适时机
6. **达到上钩点**：观察IOI信号，确认组合已被打开
7. **转移焦点**：从团体话题转向目标，开始A2阶段

---

## B 边界

**适用范围**：
- 夜店、酒吧、派对、餐厅、社交活动等线下场景
- 2人以上的女性组合
- 需要快速建立社交认证的场合

**不适用**：
- 线上搭讪（社交媒体、约会App）
- 女性明确表示不希望被打扰的场合
- 对方处于紧急状态或不便交流时

**双人组特殊处理**：
- 优先搞定障碍者，再转向目标
- 否定目标反而能让障碍者感到优越而接纳你
- 不要单独盯着目标看，像在"追"她

**核心原则**：
- 永远不要让目标觉得你是来"追"她的
- 让目标觉得是你"筛选"她，而不是她"拒绝"你
