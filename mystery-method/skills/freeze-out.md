# SKILL: freeze-out — 冷冻机制

## R 原文引用

> "当你们在吸引力阶段，你可以跟她互相调侃吐槽。但是一旦进入舒适感阶段，如果她吐你槽，你只能用撤回注意力的方式冷冻（freeze-out）她。她会问：'怎么了吗？'你说：'没事。'（不要情绪化！表达方式必须真诚，像是真的没什么事。）然后她被你的沉默惩罚，经过了尴尬的片刻，找个理由给他IOI，恢复舒适感。"

> (第3210-3212行)

## I 方法论骨架

```
冷冻的本质：用撤回注意力来惩罚负面行为，制造别扭感。

┌─────────────────────────────────────────────────────────────────┐
│ 舒适感阶段的冷冻                                                 │
├─────────────────────────────────────────────────────────────────┤
│ 她吐你槽 → 你不反击 → 沉默 → 她感到别扭                        │
│ 效果：训练她不要吐你槽                                          │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ LMR阶段的冷冻                                                    │
├─────────────────────────────────────────────────────────────────┤
│ LMR太强 → 你突然停止 → 做别的事                                │
│ 效果：她感到损失，反而想继续                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 冷冻执行要点                                                     │
├─────────────────────────────────────────────────────────────────┤
│ 必须真诚：不像是故意惩罚她                                      │
│ 不能情绪化：不是赌气，是真的没兴趣                              │
│ 轻微的：不是彻底无视，是稍微抽离                                │
└─────────────────────────────────────────────────────────────────┘
```

## A1 书中案例

**C阶段的冷冻训练**（第3031-3037行）：

> 当你们在吸引力阶段，你可以跟她互相调侃吐槽。但是一旦进入舒适感阶段，如果她吐你槽，你只能用撤回注意力的方式冷冻她。她会问："怎么了吗？"你说："没事。"然后她被你的沉默惩罚，经过了尴尬的片刻，找个理由给他IOI，恢复舒适感。

> 她会很快学会不要吐你的槽，因为（1）你已经证明了你可以（在吸引力阶段）反击，而且（2）每当她吐你槽就会感觉尴尬。

**LMR冷冻**（第3697行）：

> 如果最后一刻的抵抗似乎无法克服，就使出冷冻：开灯，吹熄蜡烛，开电脑上网收信，走到厨房去做三明治。

## A2 触发场景 + 语言信号

**触发场景**：
- C1阶段：她开始吐你槽时
- LMR阶段：她抵抗太强时
- 她做了负面行为时

**冷冻信号**：
- 她吐你槽（调侃/讽刺）
- 她表现得很讨厌
- 她的肢体语言负面
- 她的言语攻击你

**冷冻后的信号**：
- 她问"怎么了吗"
- 她开始紧张
- 她尝试重新互动
- 她主动给你IOI

---

## E 可执行步骤

1. **识别负面行为**：她吐你槽、表现讨厌、肢体语言负面
2. **立即抽离**：不说话、不看她、转身
3. **保持沉默**：让她经历别扭的片刻
4. **真诚表达**："没事"——不是赌气，是真的轻微失去兴趣
5. **等待IOI**：她会主动来找你
6. **奖赏她**：给她IOI表示她做对了
7. **LMR冷冻变体**：开灯/做三明治/下棋——表示你没性趣了

---

## B 边界

**适用范围**：
- C1阶段：训练她不要吐你槽
- LMR阶段：摧毁她的抵抗
- 任何她表现负面的时候

**不适用**：
- A1-A2阶段——那时应该调侃回去，不是冷冻
- 她真的生气时——需要处理情绪而非冷冻
- 她不尊重你时——需要更明确的边界

**关键警告**：
- 冷冻是训练，不是惩罚
- 不能情绪化，要真诚
- 不能过度冷冻，是轻微抽离
- 冷冻后必须给她IOI，否则她会觉得被遗弃
