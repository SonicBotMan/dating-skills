# SKILL: 收场技巧 (Close Technique)

## RIA++格式

### R - 原文 (Raw)
"亲吻收场有三种状况。第一，她愿意，你直接亲她。第二，也许或犹豫，你可以说"来试试看"，然后亲她。第三，她不要，你可以说"我又没说你可以，你有企图喔"然后亲她。"

"三秒亲吻判断：当你们坐得很近时，让对话减少，然后沉默。看她的眼睛。如果她回看你三秒，表示她想接吻。"

### I - 骨架 (Inner Structure)
**收场的三种情境**:

| 情境 | 她的反应 | 你的行动 |
|------|----------|----------|
| 愿意 | 主动靠近/眼神暗示 | 直接亲 |
| 犹豫 | 不确定/等什么 | "来试试看" |
| 不要 | 推开/回避 | "你有企图喔" |

**核心心态**: 主动承担风险，不要等她"允许"

### A1 - 案例 (Case)
**谜男课程中的示范**:
谜男："如果她犹豫，你可以说：'来试试看'然后亲她。如果她说不要，你可以说：'我又没说你可以。'"

**型男亲吻凯洛琳的时机**:
"我靠近，她靠近，她闭上眼睛，我也闭上眼睛，我们的嘴唇碰触。"

### A2 - 触发器 (Trigger)
- 对话进行顺利
- 她展示IOI（兴趣指标）
- 身体已经很近
- 沉默出现

### E - 执行 (Execute)
**亲吻收场流程**:
1. 创造身体接近
2. 减少对话
3. 眼神确认（看她3秒）
4. 如果她回看 = 吻
5. 如果她回避 = 退一步继续聊

**犹豫时可以说**:
- "来试试看？"
- "我不确定你敢不敢"
- "你闻起来好香"

**她拒绝时**:
- "我有说你可以说不要吗？"
- "你怕什么？"
- 轻微后退，看她反应

### B - 边界 (Boundary)
**有效边界**:
- 她没有明显抗拒
- 她没有男朋友在场
- 私密空间（非公众场合）

**危险边界**:
- 她明确说"不要"
- 她在打电话/明显在忙
- 她朋友正在看着她
- 她喝醉/无法做决定

### 扩展说明
收场的关键是果断。不要问"我可以吻你吗"，而是直接创造时机然后行动。等待"许可"反而会让气氛尴尬。
