# SKILL: 否定技术 (Neg)

## RIA++格式

### R - 原文 (Raw)
"否定既非恭维亦非冒犯、介于两者之间，是一种无意的冒犯或暗藏讽刺的恭维。否定的目的是贬抑一个女人的自尊，主动表现出对她兴趣缺缺——举例来说，指出她牙齿上沾到了唇膏，或是在她讲话之后递给她一片口香糖。"

"我不孤立丑女，也不孤立男生，我只孤立我想要上的女生。"

"如果你不信，今晚就是实验之夜，你将亲眼目睹。"（第二章第2节，谜男课程）

### I - 骨架 (Inner Structure)
**目的**: 打破美女的"被追求"期待

**效果**: 
- 让她不把你当作普通粉丝
- 创造情绪波动
- 建立平等互动

**核心原则**: 轻微冒犯，让她知道你不是她的粉丝

### A1 - 案例 (Case)
**场景1 - 铂金姊妹（迈阿密）**
谜男/型男对两个10分美女说：
"你们看起很像奇怪的小雪花。"
（模糊、刺激但不构成冒犯）

**场景2 - 芭莉丝·希尔顿**
老爹对星巴克遇到的芭莉丝说：
"你有小甜甜布兰妮的微笑，好吧，那是我前女友说的。我的意思是，她觉得有C形齿的女孩……无论勾搭过多少家伙，都会被认为是好女孩。"

### A2 - 触发器 (Trigger)
- 美女表现出"理所当然被追求"的态度
- 她用鼻孔看人/态度高傲
- 周围男人都在恭维她
- 你想让她注意到你

### E - 执行 (Execute)
**否定话术库**:
1. "你的指甲好漂亮，是真的吗？"（质疑她的美丽是假的）
2. "你的头发颜色很好看，是染的吧？"（暗示不天然）
3. "你们看起很像奇怪的小雪花"（模糊否定）
4. "她要求还真多啊"（对第三方说，暗指目标）
5. 指出她牙齿上的唇膏/化妆瑕疵

**关键**: 说完就走，不要过度解释

### B - 边界 (Boundary)
**有效边界**:
- 轻微、模糊的冒犯
- 不涉及人身攻击
- 保持微笑和轻松氛围

**危险边界**:
- 不要说她是"丑女"
- 不要涉及身体缺陷
- 不要让她在朋友面前丢脸
- 绝不能真的侮辱她

**反面教材**:
"你长得真丑" = 过度，不是Neg

### 扩展说明
否定不是羞辱，而是"我对你没兴趣"的信号。目的是让她反过来想要证明给你看。猫绳理论的实践：你越是表现得不在乎，她越是想追你。
