# SKILL: 上钩点 (Hook Point)

## RIA++格式

### R - 原文 (Raw)
"你们要达到'上钩点'，就是你们要接近的女人喜欢你们的陪伴，而不是想要你们离开的时刻。"

"她不想让你离开，想要继续和你说话。"

"我已经打到她们的世界，展示权威。为了趁胜追击，我又多丢了一个否定，但是稍微用称赞软化它，仿佛她们赢得我的好感：'而且你知道吗？你的微笑很美。'"

### I - 骨架 (Inner Structure)
**定义**: 女人从"应付你"转变为"想继续和你互动"的那个时刻

**标志特征**:
- 她开始主动延续对话
- 她的肢体语言开放
- 她不看向别处/想离开
- 她开始问你问题

**达到上钩点后的策略**: 
- 可以放松，停止过度表演
- 专心了解她
- 建立真正的连接

### A1 - 案例 (Case)
**铂金姊妹案例（迈阿密）**:
"我打进去了，现在吓傻的是她们。正如罗斯曾经对我做的那样，我已经打进她们的世界，并展示了权威。"

"她们把她的胸部压在我身上。我的余光瞥见一旁的谜男、暴走和爱的斗牛士正为我鼓掌。"

**芭莉丝·希尔顿案例**:
"我们走到柜台，她拿了她的食物。我假装正要离开，但还没有使出绝招……她放下食物然后看着我。"

### A2 - 触发器 (Trigger)
- 完成开场并获得正面回应
- 她没有立刻找借口离开
- 她开始对你展示好奇心

### E - 执行 (Execute)
**识别上钩点**:
1. 对话自然延续（不是问答式）
2. 她主动延伸话题
3. 她微笑/眼神专注
4. 她问你问题

**达到上钩点后应该**:
1. 停止"表演"
2. 放松做自己
3. 真诚对话
4. 了解她的背景/兴趣
5. 建立情感连接

**没达到上钩点就推进会怎样**:
- 显得太急切
- 对方会抗拒
- 被贴上"推销员"标签

### B - 边界 (Boundary)
**上钩点vs未上钩点**:
| 未上钩 | 已上钩 |
|--------|--------|
| 她礼貌回应 | 她主动延续 |
| 她在等人 | 她在专注 |
| 想结束对话 | 想继续 |
| 身体后退 | 身体前倾 |

**注意**: 有时候需要"上钩点之前"多轮互动才能确认

### 扩展说明
上钩点是把妹过程中的第一个关键里程碑。在那之前，你是推销员；在那之后，你是她想认识的人。
