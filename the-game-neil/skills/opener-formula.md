# SKILL: 开场白公式 (Opener Formula)

## RIA++格式

### R - 原文 (Raw)
"开场白(OPENER)就是一套准备好的剧本，用来开始和一群陌生人交谈；那是任何想要把妹的人必备的第一样东西。"

"当你看见一群人当中有你喜欢的女孩，就这么说：'嘿，看来这里的派对已经结束了。'然后转头对你喜欢的女孩说：'我要不是同志的话，你还真是我的菜。'"

"伪装用的开场白：'嗨，你们对这里的第一个印象是什么？不是我的手，是这些黑色指甲。'"

"开场白是随意的，那不被认为是一种把妹的企图。你只是当个友善的陌生人，走上前去问她们。"

### I - 骨架 (Inner Structure)
**开场白的目的**: 打破沉默，建立联系

**开场的心理障碍**: 女人第一反应是"他要干什么"——需要立刻给出答案

**开场白类型**:
1. **自然开场**: 基于当前环境的观察
2. **伪装开场**: 假装问时间/问路等借口
3. **直接开场**: 直接表示兴趣
4. **幽默开场**: 引发笑声

### A1 - 案例 (Case)
**谜男的标准伪装开场**:
"你们对这个的第一个印象是什么？不是我的手，是这些黑色指甲。"
（实际上是在展示自己的指甲油，制造话题）

**演化瞬移开场（型男版）**:
"嘿，看来这里的派对已经结束了。我要不是同志的话，你还真是我的菜。"
（先否定自己是同志，再表达兴趣，制造反差）

**杂耍人的随机开场**:
"你好吗？"（最简单有效的开场）

### A2 - 触发器 (Trigger)
- 进入一个有很多陌生人的场所
- 看到你想认识的人
- 想打破沉默开始对话

### E - 执行 (Execute)
**标准开场流程**:
1. 3秒内行动
2. 走向目标/团体
3. 展示轻松自信的身体语言
4. 使用开场白
5. 如果对方回应，继续推进

**话术库**:
```
"你们觉得这里怎么样？"
"我朋友刚买了两只狗，她想用八O或九0年代的流行二重唱来命名，你们有什么想法吗？"
"你们认识很久了吗？"（用于团体）
"你的头发是真的吗？"（用于长发美女）
"我打赌你一定很快又会回来，我可以……"（用于服务生）
```

**禁忌**:
- 不要说"你真漂亮"（太俗）
- 不要问"你有男朋友吗"（目的性太强）
- 不要盯着她看超过3秒

### B - 边界 (Boundary)
**有效边界**:
- 团体开场（安全）
- 伪装开场（安全）
- 幽默开场（最安全）

**危险边界**:
- 直接说"我想上你"（太直接）
- 用猥亵语言（违法）
- 在对方明确拒绝后继续

### 扩展说明
开场白的关键不是说什么，而是开口说话。女人会原谅你说错话，但不会原谅你的沉默。
