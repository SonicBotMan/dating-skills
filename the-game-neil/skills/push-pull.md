# SKILL: 推拉法 (Push-Pull)

## RIA++格式

### R - 原文 (Raw)
"推拉法——先亏再捧，让她心里一直上上下下。"

"举例来说，如果她打断你，你可以说：'哇，她一直都是这样的吗？你们都拿她怎么办？'如果她看起来很震惊，你就用小小的称赞把她拉回来。"

### I - 骨架 (Inner Structure)
**定义**: 交替使用"推开"和"拉近"的互动方式

**推开(Push)**:
- 轻微否定
- 调侃/嘲笑
- 假装不感兴趣

**拉近(Pull)**:
- 称赞
- 展示兴趣
- 温暖的话语

**效果**: 
- 创造情绪波动
- 让她猜不透你的意图
- 增加吸引张力

### A1 - 案例 (Case)
**谜男对铂金10分**:
推开: "你们看起很像奇怪的小雪花"
拉回: "而且你知道吗？你的微笑很美"

**型男对凯洛琳**:
推开: "你的头发颜色很好看，是染的吧？"
拉回: "但你的眼睛真的很特别"

**典型对话**:
男: "你说话真的很多"（推）
男: "但我喜欢听你说话"（拉）

### A2 - 触发器 (Trigger)
- 她表现得太自信/太得意
- 气氛变得平淡
- 你想测试她的反应
- 你想制造情绪波动

### E - 执行 (Execute)
**推拉话术库**:
```
推: "你真的很自恋"
拉: "不过我喜欢自信的女生"

推: "你一定被很多男人追吧"
拉: "但你看起来不像那么俗的"

推: "我以为你会更漂亮"
拉: "原来是我看走眼了"

推: "你很会逗人"
拉: "但是讲笑话的部分让我觉得好笑"
```

**节奏**: 
- 1推1拉 或 1推2拉
- 不要连续推（会显得刻薄）
- 不要连续拉（会显得谄媚）

### B - 边界 (Boundary)
**有效边界**:
- 轻微的推/拉
- 保持微笑氛围
- 随后立即平衡

**危险边界**:
- 连续推超过2次
- 推的力度太大（变成真的否定）
- 在公众场合让她丢脸
- 对自尊心强的女性过度使用

### 扩展说明
推拉法的精髓是让她"追逐你的认可"。你推开一点，她就想证明给你看；你拉近一点，她就会更努力。
