# SKILL: 时间限制 (Time Constraint)

## RIA++格式

### R - 原文 (Raw)
"给自己一个假性时间限制：'我只能待一下下。'当你加入一个团体的时候，告诉他们：'我还得回我朋友那里。'"

"当你开始和一群人说话的时候，他们关心的第一件事是'我们得整晚都和这家伙耗吗？我们要怎么摆脱他？'"

"给女人另一个假性时间限制：告诉她你必须早睡，因为你明天有很多工作。"

"时间限制让女人不会焦虑，因为她知道不会整晚被缠住。"

### I - 骨架 (Inner Structure)
**时间限制原理**: 解除"被推销"的焦虑

**女人的顾虑**: "这个人会一直缠着我吗？"

**时间限制的回答**: "不，我不会赖着不走"

**效果**:
- 让她放松警惕
- 让她更愿意和你互动
- 为后续"离开/留下"制造选择空间

### A1 - 案例 (Case)
**假性时间限制（团体）**:
"我只能待一下下，因为我朋友在那边等我"

**即时约会的时间限制**:
"你只能进来十五分钟，然后我就得把你踢出门了"

**型男的标准说法**:
"我只能够待一下下，待太久会无聊"

### A2 - 触发器 (Trigger)
- 加入一个新团体
- 进入一个新环境
- 带她回家前
- 你想让她对下一步放松

### E - 执行 (Execute)
**时间限制话术**:
```
加入团体时：
"我只是路过，待一下就走"

对话中：
"我待会儿还有个约会"

邀请她时：
"你可以过来坐坐，但我待会儿要工作"

离开前：
"我该走了，但……"
```

**注意**: 时间限制是"工具"，不是真的限制

### B - 边界 (Boundary)
**有效边界**:
- 保持自然
- 符合情境
- 不要过度使用

**危险边界**:
- 让她以为你真的要走
- 太早给出时间限制
- 违反自己的限制（显得不真诚）

### 扩展说明
时间限制的本质是"消除压力"。当女人知道你可以随时离开，她反而会更想留住你。
