# SKILL: 冷读 (Cold Reading)

## RIA++格式

### R - 原文 (Raw)
"冷读就是不说也知道。"

"如果你充满热忱且正确地描述任何事，人们听了会想尝试——尤其你不让他们有机会拒绝的时候。"

"你可以告诉她：'你和朋友在一起时很活泼，但独处时很安静。'大多数人都会相信这句话。"

"观察人们说话时眼球移动的方向，就可以判断出他们有没有说谎。"

### I - 骨架 (Inner Structure)
**冷读原理**: 说出一个模糊但大部分人都会认为"很准"的描述

**巴南效应**: 一个模糊的描述会被当事人自动匹配到自己的特点

**有效冷读特征**:
- 正反两面都说（如：活泼vs安静）
- 大部分人都有的特点
- 带有轻微神秘感

### A1 - 案例 (Case)
**立方体测验（老爹对芭莉丝）**:
"想象你正在沙漠中开车，然后你看见一个立方体。那个立方体有多大？"
"嗯，有意思。它是什么颜色的？"
"好，粉红色是一种代表爱玩与开朗的色彩。你会选这个颜色是因为你身上也带着同一种能量。"

**型男对小甜甜布兰妮**:
"你说话的时候，我观察了你的眼睛。你在思考时，眼球就往下而且往左移动，那代表你是'动觉型'的人。你是那种活在自我感觉中的人。"
"喔，我的天，完全正确！"

**心灵感应游戏**:
"想一个G或C开头的名字...我感觉是G。你想到了什么？"

### A2 - 触发器 (Trigger)
- 你想展示自己"了解"她
- 气氛有点尴尬需要打破
- 你想建立特殊连接感
- 你想让对方相信你有特殊能力

### E - 执行 (Execute)
**基础冷读库**:
```
"你表面看起来很自信，但内心偶尔会怀疑自己"

"你在陌生人面前很安静，但在朋友面前很放开"

"有时候你想很多东西，但很少说出口"

"你对在乎的人会变得很敏感"

"你在夜晚独处时会有一些深层的思考"
```

**眼球解读（参考）**:
- 往左下 = 回忆/过去
- 往右下 = 创造/未来
- 往左上 = 视觉记忆
- 往右上 = 听觉记忆

### B - 边界 (Boundary)
**有效边界**:
- 模糊但有趣
- 保持轻松氛围
- 观察对方反应调整

**危险边界**:
- 过于精确可能出错
- 不要冒充真正的读心术
- 不要在对方明显不信时坚持

### 扩展说明
冷读是建立"她很特别"的感觉的好方法。不是真的读心，而是创造一种"他懂我"的错觉。

## 相关技能 (related_skills)

### depends-on
- **neg-technique**: 否定建立平等后，冷读更容易被接受
- **opener-formula**: 开场成功后才有机会冷读

### contrasts-with
- **storytelling**: 冷读是即兴发挥，讲故事是有准备的（此书无故事技能）

### composes-with
- **DHV-display**: 冷读后可以顺势展示价值
- **push-pull**: 冷读可以作为"拉"来平衡否定

### 补充说明
冷读的精髓是"说对方想听的话"。巴南效应：模糊的描述会被当事人自动匹配。
