# SKILL: 进挪/肢体接触 (Kino)

## RIA++格式

### R - 原文 (Raw)
"进挪就是你碰触女人的时机。"

"进挪?女孩回问。"

"万恶走到我的身后，抬起我的手臂，放在她的肩上。'进挪就是你碰触女人的时机。'"

"宠物都喜欢被抚摸，只是猫狗乞求肉体的关爱与性无关。人类也是一样，我们需要触碰。"

### I - 骨架 (Inner Structure)
**Kino的本质**: 用肢体接触推进关系

**层级递进**:
1. 非性感的触碰（手、肩膀）
2. 轻微性感的触碰（腰、背）
3. 性感触碰（脸、腿）
4. 私密触碰（根据情况）

**核心原则**: 
- 从低层级开始
- 根据反应递进
- 她接受就继续，拒绝就退

### A1 - 案例 (Case)
**万恶指导型男**:
把型男的手放在女孩肩上，说是"进挪"

**演化瞬移惯例（型男版）**:
1. 嗅闻她："你闻起来很香"
2. 拉头发："就像狮子咬鬃毛"
3. 咬手肘内侧
4. 让她咬你脖子
5. 接吻

**谜男的标准进挪**:
- 握手开始
- 手放肩膀
- 腰侧接触
- 头发抚摸

### A2 - 触发器 (Trigger)
- 开场白成功，她回应正面
- 气氛轻松
- 她没有躲避/抗拒
- 你想推进关系

### E - 执行 (Execute)
**触碰层级**:
```
Level 1: 握手、轻拍肩膀
Level 2: 手放腰、手臂接触
Level 3: 头发抚摸、脸颊触碰
Level 4: 腰背按摩
Level 5: 大腿触碰（需非常确认接受）
```

**判断标准**:
- 她没有退开 = OK
- 她靠近/回应 = 很好
- 她回避/僵硬 = 退回

**时机**:
- 对话中自然触碰
- 讲笑话时轻拍
- 过马路时牵手

### B - 边界 (Boundary)
**有效边界**:
- 轻松自然的触碰
- 根据她的反应调整
- 保持绅士风度

**危险边界**:
- 不要从背后突袭
- 不要抓敏感部位
- 不要在她明确拒绝后继续
- 不要在公众场合过度

**注意**: 东方文化需比西方更谨慎

### 扩展说明
kino是让关系从"交谈"升级到"亲密"的关键。没有身体接触，关系永远停留在朋友区。
