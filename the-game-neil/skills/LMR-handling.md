# SKILL: 最后抵抗处理 (LMR Handling)

## RIA++格式

### R - 原文 (Raw)
"你们亲热，你脱掉她的上衣，她也脱掉你的，你开始脱她的胸罩。怎么了？她不让你更进步？PUA们对这点有个说法——'最后一刻的抵抗'（last minute resistance，简称LMR）。先后退一两步，然后继续。又来了？她只是作作样子，不想让你认为她很随便，那叫'荡妇防卫机制'（anti-slut defense，简称ASD）。"

### I - 骨架 (Inner Structure)
**LMR定义**: 性行为前最后一刻的抗拒

**ASD定义**: 女性避免被视"荡妇"的心理防御

**核心原理**: 大部分女性需要"合理化的借口"才能接受性行为

**应对策略**: 
1. 后退一两步
2. 给她台阶下
3. 重新建立舒适感
4. 再尝试

### A1 - 案例 (Case)
**型男的LMR处理示范**:
"先后退一两步，然后继续。又来了？她只是作作样子，不想让你认为她很随便。"

**史提夫·P的3P管理**:
"重点必须放在你女朋友的愉悦，不是你的。她要像领头的雪橇犬——如他所称——而你要让她觉得自在，而且很爽。"

**谜男的冷冻法**:
"你告诉她：'你说得对。'在她耳边沉重地叹气：'我们不该这么做的。'"

### A2 - 触发器 (Trigger)
- 已经脱掉部分衣服
- 她突然停止/推开你的手
- 她说"我们太快了"/"我不应该"
- 她突然变得紧张

### E - 执行 (Execute)
**LMR处理流程**:
```
1. 停止行动
2. 后退一步
3. 拥抱她/抚摸头发
4. 轻松对话："怎么了？"
5. 给她台阶："我不会介意的"
6. 等她放松
7. 重新开始
```

**话术库**:
- "你闻起来好香"
- "我们不用急"
- "我喜欢你"
- "你想怎样？"
- "我可以等"

**冷冻法**:
- 关灯/开音乐/毁掉气氛
- 停止所有触碰
- 假装做别的事
- 让她主动来找你

### B - 边界 (Boundary)
**有效边界**:
- 她只是"作样子"
- 不是真的拒绝

**危险边界**:
- 她明确说"不要"
- 她在哭/情绪崩溃
- 她明显醉酒
- 她想离开

### 扩展说明
LMR是正常的，不是拒绝。大部分女性需要感觉"不是我在随便，是自然发生的"。给她台阶下比强迫更有效。
