# SKILL: 三秒法则 (Three-Second Rule)

## RIA++格式

### R - 原文 (Raw)
"三秒法则：三秒之内看到目标到跟她说话之间。如果他花了更久的时间，不只可能会因为盯太久而被女方讨厌，还会因为过度思考如何下手，而导致紧张，结果就搞砸了。"（第二章第3节，谜男课程）

### I - 骨架 (Inner Structure)
**核心原理**: 人类的本能反应比思考更快，思考会引入焦虑

**行动指令**:
1. 锁定目标
2. 立刻行动（3秒内）
3. 不要分析，不要犹豫

**适用场景**: 夜店、酒吧、派对等社交场所

### A1 - 案例 (Case)
谜男在KeyClub示范：他大步走向一群女人，伸出他的手问道："你们对这个的第一个印象是什么？不是我的手，是这些黑色指甲。"

当那些女孩凑过来围绕着他，他立刻开始互动，没有一丝犹豫。

### A2 - 触发器 (Trigger)
当你站在夜店/酒吧里，看到一个你想认识的女人 → 触发三秒法则

看见目标 → 不要想开场白说什么 → 直接走过去

### E - 执行 (Execute)
**标准流程**:
1. 看见目标
2. 停止思考
3. 开始走路
4. 开口说话（任何话都可以）
5. 继续推进

**警告**: 超过3秒 = 失败概率大幅上升

### B - 边界 (Boundary)
**有效边界**:
- 任何你想要的社交场合
- 对任何你想要的女性

**无效/危险边界**:
- 已经明确拒绝你的女性
- 对方明显在忙/不适宜打扰
- 厕所等私密场所强行接近

### 扩展说明
三秒法则是谜男方法的基础中的基础。它解决的不是说什么的问题，而是什么时候行动的问题。本质是:
- 消除思考时间
- 避免焦虑累积
- 利用本能反应
