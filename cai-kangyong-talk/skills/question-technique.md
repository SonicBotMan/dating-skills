## R 原文

"'你喜欢去什么样的国家旅行？'比不上'你旅行时有被骗过钱吗？'"

"'你喜欢什么样的男生？'比不上'你喜欢王力宏那样的男人吗？'"

"问问题，最好有'退路'，也就是说，就算对方回答'没有被骗过钱'或者'对王力宏那型的男人没有感觉'的时候，你自己应该也有些相关的有趣的事可以讲。"

## I 骨架

**好问题 = 具体 + 有退路**：
- 具体问题 > 抽象问题（更易回答）
- 有退路 = 她回答后你也能接着说
- 让她有发挥空间

## A1 案例

**对比**：
```
差：你喜欢什么样的电影？
好：你喜欢看喜剧还是悲剧？
→ 她必须选一个，你可以说"为什么"

差：你觉得怎么样？
好：你觉得这部电影比上一部好看吗？
→ 回答"是"或"不是"都有话说

差：你平时喜欢干嘛？
好：你周末一般睡到几点？
→ 具体到能回答的问题
```

**退路设计**：
```
问：你旅行时被坑过吗？
→ 她说"有" → 你问"被坑了多少"
→ 她说"没有" → 你说"那你运气好，我上次..."
→ 不管怎样你都有话说
```

**连续具体问题**：
```
问：你去过泰国吗？（判断是否去过）
问：那你觉得清迈好还是曼谷好？（具体到城市）
问：你在那边买什么东西了吗？（问她经历）
→ 从宽到窄，引导她发挥
```

## A2 触发

"我问她问题她总是回答很敷衍"
"她总是说'还好吧''都可以'"

→ 触发：问的问题太抽象，对方不知道怎么回答

## E 执行

**问题设计原则**：
1. **具体 > 抽象**
   - "你喜欢吃什么" → "你喜欢川菜还是粤菜"

2. **有退路**
   - 对方回答后你也能接着说
   - 要设计好"后续问题"

3. **让她发挥**
   - 问经历 > 问看法
   - 问感受 > 问想法

**从宽到窄技巧**：
1. 先问大方向（判断类型）
2. 再问具体细节（她发挥）
3. 最后问感受/原因（深入）

**禁忌**：
- 不要问"你觉得怎么样"（太宽）
- 不要问"你喜欢oxx吗"（封闭式）
- 不要问太私人的问题（收入、年龄）

## B 边界

- 连续追问会像查户口
- 要留给她说话的空间
- 不是问越多越好
- 要根据她的回答调整问题
- 有些问题太具体会显得刻意
