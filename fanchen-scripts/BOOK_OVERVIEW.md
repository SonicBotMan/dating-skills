# 梵尘话术 - BOOK OVERVIEW

## 基本信息
- **书名**: 梵尘话术
- **作者**: 梵尘团队（拉斐尔、型男、慕斯）
- **类型**: PUA话术惯例集
- **日期**: 2015年2月14日
- **来源**: PUAFUN团队整理梵尘线下课程内容

## 核心定位
梵尘话术是PUA圈内的话术惯例集，核心概念是"表演性人格"。贯穿白天约会和夜场KTV全流程：认识→建立吸引→联系感→筛选→推拉→情绪操控→关系升高→TD。

## 内容结构

### 第一章：聊天基本模型
五大阶段（遵循女人情感进展）：
1. **建立娱乐性** - 刺激女生情绪，调侃、幽默、推拉
2. **安全感和联系感** - 交换生活信息，建立信任
3. **情绪共振** - 共同记忆、话题引发共鸣
4. **情感链接** - "他懂你"的深层连接
5. **邀约** - 模糊邀约→具体邀约

### 第二章：开场白
三类开场白：
- **价值型开场**: 提高价值展示，吸引回复
- **好奇型开场**: 勾起好奇心，让她主动提问
- **筛选型开场**: 直接表情或简短筛选

### 第三章：娱乐性
- **角色扮演**: 泰坦尼克号等场景化对话
- **夸张、曲解**: 曲解对方话语制造幽默
- **善意的耍女生**: 调侃、昵称、推拉
- **推拉**: 先推后拉，制造情绪波动
- **表演性人格**: 营造情绪、控制氛围

### 第四章：安全感与联系感
- **SOI表达兴趣**: 暧昧声明
- **筛选、信息交换**: 问问题、DHV
- **DHV建立**: 展示上进心、孝心、细心

## 核心方法论
55-38-7法则：55%打扮和肢体语言，38%语音语调，7%说话内容。话术惯例不重要，重要的是揣摩何时说、为何说、达到什么效果。

## 关键技能提取
1. 开场白设计（价值型/好奇型/筛选型）
2. 娱乐性建立（角色扮演、夸张曲解、推拉）
3. 情绪刺激技术
4. 表演性人格运用
5. 安全感与联系感建立
6. 模糊邀约技巧
