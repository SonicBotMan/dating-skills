## R 原文

"推拉的核心在于制造情绪波动，让女人对你产生情绪投入"

**推拉话术示例**：
- "你脑门挺大的，应该挺聪明的吧"
- "眉毛挺好看的，再长一点都能夹菜了"
- "你的眼睛挺大的挺好看，像我以前养过的一条金鱼"
- "今天发型挺特别，有点像大尾巴狼呢"
- "你的眼睛像万花筒"
- "这条裙子挺漂亮的，以前我姥姥家的窗帘也是这个颜色"
- "发现我们一个共同点，就是都靠脸吃饭的，但是我跟你还有一点不同，就是我还有一些内涵"

## I 骨架

**推拉是情绪操控的核心**：
- 推 = 调侃、打压、否定（让她情绪波动）
- 拉 = 赞美、认同、亲近（让她感觉被喜欢）
- 顺序：先推后拉，效果最佳

**底层逻辑**：
- 只推不拉 = 得罪人
- 只拉不推 = 没有挑战性，不吸引人
- 推拉结合 = 情绪波动，欲罢不能

## A1 案例

```
男：发现我们一个共同点，就是都靠脸吃饭的，但是我跟你还有一点不同，就是我还有一些内涵
→ 先说她靠脸（推），再说自己有内涵（拉），同时暗示她没内涵

男：你的眼睛挺大的挺好看，像我以前养过的一条金鱼
→ 说眼睛大好看（拉），但说像金鱼（推），制造反差

男：你的眼睛像万花筒
→ 表面是赞美，但万花筒是复杂的意思，实际是暗示她心思复杂
```

## E 执行

**常用推拉句式**：

1. **外貌推拉**
   - "你长得还行，但就是有点矮"（推）
   - "你的腿挺长的，就是腰有点粗"（推）
   - 先推后拉："你脾气这么大，但我就喜欢你这种有个性的"

2. **智商推拉**
   - "你脑门挺大的，应该挺聪明的吧"（看似夸实际损）
   - "眉毛挺好看的，再长一点都能夹菜了"（推）

3. **比较推拉**
   - "我发现我们一个共同点，就是都靠脸吃饭的，但我还有一些内涵"

4. **行为推拉**
   - "好啊，亲一个，一辈子好朋友"（拉后立即推开）
   - "我不会那么容易上钩，我被女朋友们培养成柳下惠"（推）

**节奏控制**：
- 1推1拉 = 小波动
- 2推1拉 = 中度波动
- 不要连续推超过2次，否则真的会得罪人

## B 边界

- 推的内容要基于事实，不能无中生有
- 推的程度要控制，不能人身攻击
- 拉要及时，推完要立刻拉回来
- 对secure型女生可多推，对anxious型要少推
- 刚认识时推拉效果最好，熟了之后要减少推的比例
