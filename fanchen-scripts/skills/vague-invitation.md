## R 原文

"通常我们要约女生前先进行模糊邀约，因为这种方式即使被女生拒绝也没有风险，当女生答应你之后再转为具体邀约，时间、地点、人物。"

"如果你要很舒适的邀约，那最好是可以再聊天的过程中进行播种，比如'今天我在建国路，吃了一个超屌的猪排饭'。通常我们要约女生前先进行模糊邀约，因为这种方式即使被女生拒绝也没有风险，当女生答应你之后再转为具体邀约，时间、地点、人物。"

## I 骨架

**模糊邀约是邀约前的测试**：
- 提出邀约概念，不明确时间地点
- 对方同意 → 说明有兴趣，可以进一步
- 对方拒绝/回避 → 说明吸引不够，退回上一步

**流程**：模糊邀约 → 对方同意 → 具体邀约（时间地点人物）

## A1 案例

**场景1：刚认识不久**
```
男：今天我在建国路，吃了一个超屌的猪排饭
女：哦？听起来不错
男：下次带你尝尝，有时间一起出来转转（模糊邀约）
女：好啊
男：那你这周六有空吗，我们去那家店（具体邀约）
```

**场景2：关系不错**
```
梵尘：咱俩离的那么近，晚上可以一起放孔明灯嘛（模糊邀约）
安喵喵：护城河边可以放河灯嘛
梵尘：可以放河灯啊，那不是有楼梯嘛（开始讨论具体）
```

## A2 触发

"我想约她出来但怕被拒绝尴尬"
"怎么判断她对我有没有兴趣"

→ 触发：不确定对方意愿，担心直接邀约被拒

## E 执行

**模糊邀约的三种形式**：

**1. 模式时间空间（最模糊）**
- "有时间一起出来转转"
- "改天一起吃饭"
- 适用：关系早期，不确定对方兴趣

**2. 模糊时间明确地点**
- "欢乐谷的过山车挺有意思的，有时间我们一起过去"
- "那家咖啡店挺不错的，改天一起去试试"
- 适用：知道她对某事有兴趣

**3. 明确时间模糊地点**
- "晚上我们一起去转转吧"
- "周六有空吗"
- 适用：已经了解她的时间安排

**模糊邀约后的处理**：
- 她同意 → 立即转具体邀约
- 她回避 → "没关系，有机会再说"，退回吸引阶段
- 她拒绝 → "理解"，不强求

## B 边界

- 模糊邀约后不要等太久，要立即转具体
- 被拒后不要追问原因，会显得需求感强
- 模糊邀约是测试，不是真的要等"改天"
- 不能连续发模糊邀约，被拒说明吸引不够
- 邀约地点要选择环境好、有人流量的地方（安全感）
