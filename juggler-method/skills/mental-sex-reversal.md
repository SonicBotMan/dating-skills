# R原文

> "思维性交是一种自成一体的艺术。它开始于一系列包括赞美、同意或者她喜欢的一切东西。然后下句话就把这些东西拿走。或者反过来做，也能达到同等效果。先做一个NEG，然后是一个肯定。拿走——给予——拿走——给予。"

# I骨架

**思维性交/逆转**是一种推拉技术，核心是让她不确定你到底喜不喜欢她。

两种形式：
1. 拿走-给予：先给赞美/兴趣，然后拿走
2. 逆转：不回答她的圈套，反过来用在她身上

效果：制造不确定性；增加吸引力；让她更想追逐你

# A1案例

**先赞后贬**：
```
你：你态度不好。
她：你在说什么啊？
你：你最好改正，我可以像这样替代你。（打响指）
她：我没有。
你：好了，过来。你知道有一种态度叫做，好色。（拥抱）
```

**逆转她的问题**：
```
她：你为什么不洗车？
你：（忽略这个问题）你打算穿那个吗？
```

# A2触发场景

触发点：她试图用问题控制你；她在测试你（废物测试）；她显得太自信

如何识别：问题不直接关于你；试图让你道歉/解释；她在建立控制

# E执行步骤

1. 识别圈套：她在问一个没有好答案的问题
2. 不进入她的框架：不要正面回答
3. 反转：把问题抛回给她
4. 或者拿走-给予：先肯定再否定
5. 保持态度轻松：不要显得你在防守

# B边界

不要：每次都逆转；逆转太明显；完全不回应
