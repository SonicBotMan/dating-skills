# R原文

> "当你搭讪女孩时，structure（架构）非常重要。根据这个架构，构想你最后的收场。1. 开场（1分钟）2. 设定情绪或者娱乐（10分钟）3. 筛选/EV（5分钟）4. 收场。这个架构并不基于一些IOI。如果她进入了你设定的情绪，这就是你的指标——你可以收场了。"

# I骨架

**Structure四步架构**是一个时间分配框架，让你清楚每个阶段的目标和时间投入。

| 阶段 | 时间 | 目标 | 成功指标 |
|------|------|------|----------|
| 开场 | 1分钟 | 引起注意 | 她愿意继续对话 |
| 情绪/娱乐 | 10分钟 | 建立和谐感 | 她在笑、靠近、给IOI |
| 筛选/EV | 5分钟 | 了解她的价值观 | 她开始问你问题 |
| 收场 | - | 约定下一步 | 得到号码/约定见面 |

# A1案例

**错误用法**：开场后直接问名字；聊了30分钟还没收场；收场太早

**正确用法**：
```
阶段1："你知道吗，你是我今天看到的第三个让我忍不住想过来打招呼的人。"
阶段2：讲有趣的故事、调侃、kino，制造轻松氛围
阶段3："如果可以回到十岁，你知道你最想做的是什么吗？"
阶段4："你应该有空吧？我们可以找个时间再聊，或者...你给我你的号码？"
```

# A2触发场景

开场→情绪：她没有走开，愿意听你继续说
情绪→筛选：她在笑、给IOI、主动问你问题
筛选→收场：她的回答显示出对你的兴趣

# E执行步骤

1. 开场时：简洁有力，不要解释为什么搭讪她
2. 情绪阶段：90-10规则，讲故事，制造轻松氛围
3. 筛选阶段：问她深层问题，同时展示你的
4. 收场时：要么当场约定下次见面，要么得到号码

# B边界

不要：在情绪阶段没建立好时就急着收场；筛选阶段问太多问题；超过20分钟还没收场
