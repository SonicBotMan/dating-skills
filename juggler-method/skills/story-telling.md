# R原文

> "好的故事有三个要素：感官细节（看、听、感觉、味道）、一个转折或意外结果、情感起伏。你在讲的时候要展现出来，而不是说出来。如果你用细节让女孩在脑中产生画面，她就会开始投入。如果你讲的时候像在报告事实，她就不会有任何感觉。"

# I骨架

**讲故事**的核心是让女孩在脑中产生画面，而不是听你说教。

故事三要素：
1. **感官细节**：看得见、听得见、感觉到
2. **转折/意外**：打破预期
3. **情感起伏**：让她笑、惊讶、感动

表现形式：展现出来（声调、手势、停顿）vs说出来（平淡陈述）

# A1案例

**糟糕的故事**："我以前在一家公司工作，老板很糟糕，经常让我加班。"

**好的故事**：
"你知道那种感觉吗？凌晨两点，办公室只有我一个人，荧光灯嗡嗡响，桌上的咖啡已经凉透了。我抬头看窗外，整个城市都睡了，只有我的影子还醒着。就在那一刻，我决定...

（停顿）

我要去搭讪那个便利店店员。"

# A2触发场景

什么时候用：90-10规则时；需要建立情绪时；对话变得无聊时

什么样的故事：真实的、有画面感的、有你自己的立场的

# E执行步骤

1. 选择有转折的故事：不是平铺直叙
2. 加入感官细节：地点、声音、感觉
3. 展现出来：语调变化、手势、停顿
4. 和她有关：最后把她拉进来
5. 练习：每个故事讲3遍以上

# B边界

不要：讲别人的故事；太长太复杂；说教味道；没有情感起伏
