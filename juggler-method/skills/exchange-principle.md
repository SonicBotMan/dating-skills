# R原文

> "秘诀就在于交换。不要给她任何东西，除非她先为你做些什么。举个例子：你'如果你给我做背部按摩，我就告诉你一个秘密。'这就是你所要的谈话动力。人们只会在意那些只有付出才会赢得的价值。"

# I骨架

**交换原则**是一种价值保护机制，核心是"不给免费午餐"。

为什么有效：
- 人只珍惜自己付出代价得到的东西
- 免费的东西不会被珍惜
- 交换让对方有"赢得"你的感觉

可以交换的东西：按摩换秘密；买饮料换电话号码；她的kino换你的故事

# A1案例

**获得电话号码**：
```
她：你给我你的号码吧。
你：好，不过你要先答应我一件事。下次见面的时候，你要准备一个有趣的故事讲给我听。
```

**讲故事**：
```
你：如果你给我做一个背部按摩，我就告诉你一个秘密。
她：什么秘密？
你：（先亲她一下）我经常想起你。
```

# A2触发场景

触发点：她要求什么（电话号码）；她问你的情况；她想让你做什么

如何判断：她为得到你的关注付出了努力→可以给；她只是伸手要→不要直接给

# E执行步骤

1. 当她要求时：不要立刻给
2. 提出交换条件：要具体、有趣、和她有关
3. 推拉：她可能会讨价还价，继续推拉
4. 她付出后：兑现你的承诺
5. 保持框架：是你在主导这个交换

# B边界

不要：对方什么都没做就给号码；交换条件太无聊；交换后不兑现
