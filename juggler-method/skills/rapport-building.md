# R原文

> "在筛选阶段，你不是在问她问题然后分析答案。你是在和她一起创造一种情绪上的共鸣。如果她分享了什么，你要分享一个类似的故事。如果她表达了什么感受，你要展示你也经历过类似的。你不是在审问她，你是在和她一起探索彼此的内心世界。"

# I骨架

**和谐感建立**的核心是情绪共鸣而不是逻辑分析。

怎么做：
1. 她分享什么→你也分享类似的
2. 她表达感受→你展示也经历过
3. 你们是"同类人"的感觉

不是在审问：不是问完就走；不是记录答案分析；不是做笔记

# A1案例

**她**："我其实经常觉得孤独，即使在人群中也是。"
**你**："是啊，那种感觉我也懂。有一次在公司派对上...（你的类似经历）"

→ 你们现在有共鸣了

**她**："我上周刚和我最好的朋友吵架了。"
**你**："我懂，我上次和朋友吵架是...那次经历真的很伤人。"

# A2触发场景

什么时候：在筛选问题的回答后；她分享了任何东西

时机：立即回应，展示你也懂

# E执行步骤

1. 认真听她说什么
2. 识别她表达的情绪（孤独、快乐、悲伤、愤怒）
3. 分享一个类似的经历或感受
4. 不要比惨：重点是共鸣，不是你比她更惨
5. 保持眼神接触和开放的身体语言

# B边界

不要：听完就讲你自己的故事（打断她）；比惨；假装共鸣（她能感觉到）
