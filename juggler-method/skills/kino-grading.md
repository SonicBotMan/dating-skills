# R原文

> "Kino的关键是渐进式升级。不要从亲吻开始。从手开始，然后手腕，然后手臂，然后肩膀，然后腰，然后头发，然后脸，然后嘴唇。不要跳级。每一步都需要她接受。如果她在某一步拒绝，你就退回上一步。你要让她习惯你的触碰。"

# I骨架

**Kino分级**是一种渐进式肢体接触升级技术，核心是让她习惯你的触碰。

分级（从低到高）：
1. **低级触碰**：手→手腕→手臂（安全区域）
2. **中级触碰**：肩膀→腰→头发（需要一定舒适度）
3. **高级触碰**：脸→嘴唇（需要高度亲密）

原则：
- 每次只升一级
- 拒绝→退回上一步
- 接受→可以继续
- 不要跳级

# A1案例

**正确的渐进**：
```
1. 你：你的戒指很好看。（碰她的手）
2. 你：你的皮肤很软。（碰她的手腕）
3. 你：你的姿态很好。（碰她的肩膀）
4. 你：（帮她弄头发）这里有个东西。
5. 你：（轻轻碰她的脸）你的脸型很好看。
6. 你：（看她的嘴唇）你知道吗...
```

**错误的做法**：
- 一上来就想吻
- 触碰敏感部位（腰、臀）太早
- 不看她的反应

# A2触发场景

什么时候开始：在开场后、情绪阶段

怎么开始：用"你的XX很好看"作为触碰的借口

# E执行步骤

1. 用合理的借口触碰（看戒指、看手相）
2. 触碰时观察她的反应
3. 如果接受→继续下一步
4. 如果拒绝→退回上一步，过一会再试
5. 永远不要忽略她的拒绝

# B边界

不要：跳级；忽略拒绝；触碰敏感部位太早；没有借口直接碰
