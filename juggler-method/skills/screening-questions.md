# R原文

> "筛选问题应该测试她的核心信念和价值观，而不是她的外在条件。你需要了解她是谁，而不是她看起来怎么样。比如问她'你最好的朋友会怎么形容你？'而不是'你做什么工作？'问有关她如何对待他人的问题，看她是否善良。问有关她如何面对逆境的问题，看她是否坚强。"

# I骨架

**筛选问题**的目的是了解她的核心价值观，不是外在条件。

两类问题：
1. **关于她自己**：最好的朋友怎么形容她；她的梦想；她如何面对困难
2. **关于她如何对待他人**：她上次帮助陌生人是什么时候；她怎么看前任

避免问：工作、收入、外表（这些不重要）

# A1案例

**深层问题示例**：
- "如果可以回到十岁，你知道你最想做的是什么吗？"
- "你最好的朋友会怎么形容你？"
- "你上一次在公共场合哭是什么时候，为什么？"
- "如果明天你赢了彩票，你会怎么分配这笔钱？"

**筛选标准**：
- 她的回答是否有深度
- 她是否愿意分享
- 她的价值观和你的是否一致

# A2触发场景

什么时候问：在情绪阶段之后，收场之前

注意：用自然的方式问，不要像面试

# E执行步骤

1. 问一个开放性的深层问题
2. 听她的回答（不要急着说你的）
3. 根据她的回答判断她的价值观
4. 可以追问深入
5. 展示你自己的相应观点

# B边界

不要：问太多问题；像审问；问太私人的；期望完美的答案
