# R原文

> "当你搭讪一个3人组合的时候，对话的比例是270%-30%。270%看起来很夸张。你只有一个人。努力吧。尽量接近这个比例。大方一些，一直滔滔不绝地讲。用一些可以让人想象出画面的惯例。不要指望团体会帮你什么忙，也不要指望僚机。"

# I骨架

**团体270-30规则**是90-10规则在团体场景的极端版本。

| 团体人数 | 你需要提供 | 她们总共提供 |
|----------|-----------|-------------|
| 2人 | 180% | 20% |
| 3人 | 270% | 30% |
| 5人 | 450% | 50% |

原则：你一个人vs整个团体；不能指望任何人帮你；用手势、放慢语速、制造画面感

# A1案例

**开场示例**（3人组合）：
```
你：（走近，目光扫过每个人）"你们发现一件很有趣的事了吗？当你们三个在一起的时候，最高的人总会站在最矮的人对面。就像...（指向最高的）你，和（指向最矮的）你。你们在潜意识里在远离对方。"
```
→ 你一个人提供全部谈话内容，不等待她们主动参与

# A2触发场景

什么时候适合：目标在团体中（更安全）；团体气氛开放；你有内容可以同时吸引多人

什么时候不适合：只有你和目标两个人（直接一对一）；目标显得很封闭

# E执行步骤

1. 不要等她们：直接开口，不要问"我能加入吗"
2. 用话题开场：有趣的观点、观察到的事实
3. 保持高能量：手势、语速变化、戏剧性停顿
4. 逐个拉人：每隔30秒用目光拉一个新的人进来
5. 和目标一对一：团体接纳你后，找机会和目标单独聊

# B边界

不要：指望僚机；讨好每个人；讲太短；忘记和目标单独聊
