# R原文

> "大多数情况我直接说，'其实我发现，我很喜欢女孩伺候我。我喜欢背部按摩，喜欢收到情书，喜欢躺在床上吃早餐，等等。我喜欢女孩关心照顾我。'有趣的是，这些都成真了。记住，告诉女孩你喜欢她们伺候你，并不是哄骗她们上床的方法。但这是发自你内心的想法。你有权利告诉女孩你想要什么。"

# I骨架

**自我定价**是一种设定标准的技术，核心是让她知道你的价值，并让她来赢得你。

关键点：
- 直接说出你想要什么
- 不是什么技巧，而是真诚的表达
- 给她一个可以"赢得"你的明确途径
- 她会尊重你的标准

# A1案例

**直接声明**："我喜欢被伺候。背部按摩、情书、床上早餐...我喜欢女孩对我好。"

**拒绝不符合标准的**：
```
她：（普通女孩）请我喝杯酒？
你：（笑）你知道我不是随便和人喝酒的。
```

**让她证明自己**：
```
她：你为什么不给我你的号码？
你：先告诉我，你会为什么样的人付出？
```

# A2触发场景

什么时候用：当她问你问题；当她在追求你；当你想筛选她

不要用：刚认识就摆架子；她已经很有兴趣时

# E执行步骤

1. 真诚地说出你想要什么（不是表演）
2. 设定一个她可以完成的标准
3. 看她是否愿意付出
4. 如果她付出：给予奖励
5. 如果她拒绝：继续你的生活

# B边界

不要：用这个来假装高傲；设的标准太高；用这个拒绝所有人
