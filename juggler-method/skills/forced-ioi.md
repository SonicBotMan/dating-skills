# R原文

> "强制IOI是一种技术，用来强迫女人给你IOI。基本上，你假装她对你有兴趣。比如，你指向一个方向，然后说'那边有个很酷的咖啡馆，下次我带你去。'这就强制她给你一个IOI或者ASD反应。如果她拒绝，她就需要用ASD来拒绝你的意图——这就是暴露了她的立场。如果她接受，她就默认同意了你的意图，不管这个意图有多牵强。"

# I骨架

**强制IOI**是一种迫使她表态的技术，核心是让她没有中间地带可选。

两种结果：
- **接受** = 她给了IOI（默认同意）
- **拒绝/ASD** = 她暴露了自己的立场（不是中性）

关键：不管她选哪个，你都获得了信息

# A1案例

**场景1**："下次我带你去一家很棒的餐厅，他们有种特别的鸡尾酒..."

→ 她要么接受（同意跟你出去），要么用ASD拒绝（暴露她的兴趣）

**场景2**："你知道吗，我觉得你其实挺喜欢我这种类型的。"

→ 她必须回应：否认（暴露ASD）或同意（IOI）

# A2触发场景

什么时候用：情绪阶段已经建立；你需要知道她的立场；她一直在"中立"

不要用：刚认识太早；她明显不感兴趣；她还太紧张

# E执行步骤

1. 时机：情绪好了以后
2. 陈述一个"她同意跟你做某事"的假设
3. 用平静自信的语气，像在陈述事实
4. 看她的反应
5. 不管她说什么，你都获得了信息

# B边界

不要：用问句（显得在请求）；太直接；在一个话题上反复用
