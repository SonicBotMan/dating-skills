# R原文

> "时刻记住杂耍人的90-10规则。它的意思是，在开始搭讪时你需要提供90%以上的谈话内容，让女人可以慢慢习惯并适应你们的聊天。如果一开始你就只讲50%，让女人完成剩下的50%——像普通对话那样——你一定会失望的。因为女孩只会讲10%的内容，也就是说，你们一共只讲了60%。显然不够，对话中断，搭讪失败。"

# I骨架

**90-10规则**是一种主动主导对话的技巧，核心是承担90%的谈话负担，让女孩在安全感中慢慢参与。

**适用场景**：任何搭讪的开始阶段

**执行步骤**：
1. 开场后立即进入"独角戏"模式
2. 准备好3-5个可以连续讲述的话题素材
3. 问问题时自己准备答案作为后备
4. 当女孩开始多说话时，逐渐给她更多空间

# A1案例

```
你：你十岁的时候，最想做什么职业？
她：嗯？我不记得了。
你：不记得了吗，太糟了。如果可以记住以前的那些激情，我们才可以知道现在到底什么事情可以让我们感兴趣。像我，我很清楚记得我十岁的时候想成为宇航员。我甚至有自己的训练方法...
```

→ 当女孩给不出好回答时，用你自己的回答继续话题，保持90%的内容输出。

# A2触发场景

**触发点**：女孩回答很短（"嗯"、"不知道"、"还好"）或明显在敷衍

**反应**：立即接上你的后备内容，不留尴尬的沉默

# E执行步骤

1. **开场后不停顿**：说完开场白马上进入话题
2. **准备"故事库"**：3-5个可以讲2-3分钟的真实故事
3. **每问一个问题同时准备答案**：如果她答不上来，你来接
4. **用"例如..."过渡**：当她沉默时，自然过渡到你的例子
5. **观察她的参与度**：当她问题变多、笑、靠近时，说明她在热身

# B边界

**不要**：停顿等待她说话（她会沉默）；问太多问题不接话；讲太无聊的故事

**什么时候可以打破**：当她明显被你吸引、问题很多时
