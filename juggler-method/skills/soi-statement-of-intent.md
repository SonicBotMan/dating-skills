# I骨架

**SOI（Statement of Intent，意图声明）**是一种性暗示技术，核心是让她想象亲密场景。

关键原则：
1. SOI不是请求，是假定
2. 不要用问句形式（"我可以吻你吗？"→被拒绝）
3. 让她在脑中产生画面
4. 拒绝≠失败（她的脑中已经产生画面）
5. 可以在SOI后自己否定掉

# A1案例

**直接陈述型**："我们应该找个时间去我那里，我们可以用按摩油享受一下。"

**反转否定型**："我们应该去我那里，我们可以用按摩油享受一下。""不，等等。你太高了，还是算了吧，油不多了不够你用。"

**接吻型**："如果我现在吻你，你觉得会给几分？1到10分？"

# A2触发场景

什么时候用：情绪阶段已经建立好；你已经kino过她；她没有明显抗拒

如果她拒绝：笑一笑继续聊；自己否定掉；换个话题，1分钟后再试

# E执行步骤

1. 时机：情绪好了以后再用，不要开场就用
2. 语气：平静、自信，像在陈述事实
3. 内容：描述具体场景（接吻比性更安全）
4. 观察：看她的反应再决定下一步
5. 如果拒绝：不要停顿，换话题继续

# B边界

不要：用问句；太直白；在她还紧张时用；太频繁
