# Time Constraint - 时间限制

## R: 原文
> "时间限制是让对方明白你不打算久留。在对话第一分钟内就应该提出，别让对方有机会怀疑你要讲多久。你用的开场白要套上一个时间限制，例如。『嘿，只问一旬……』或在开场过程中解释『对了，今晚是兄弟聚会，我不能跟你们聊太久。』"（第十天）

> "当你兼用时间限制跟理由，对方不用担心你的企图或盘算怎么打发你，就能放松下来听听你要说什么。"（第十天）

## I: 骨架
1. **目的**：降低威胁感，让对方知道你只是短暂停留
2. **时机**：在对话开始的第一分钟内提出
3. **方式**：口语表达 + 肢体语言配合
4. **内容**：给出合理理由，说明你为什么不能久留
5. **组合**：与开场白一起使用，不能单独使用
6. **后续**：时间限制到了仍可继续对话，但要自然

## A1: 案例
> "嘿，只问一句——我觉得你们看起来像懂音乐的人，我和朋友在争论世界有几个大洋，你们觉得有几个？"

> 另一个案例："对了，今晚是兄弟聚会，我不能跟你们聊太久，但我需要你们的意见..."

> 肢体语言：侧着身体说话、左右摇摆、边走边讲、表现急着去别处

## A2: 触发
**使用场景**：
- 任何接近陌生人的场合
- 团体（三人以上）场合
- 夜店、派对等社交环境

**语言信号**：
- "我只问一句..."
- "我马上要走了，但..."
- "只有一分钟..."
- "说起来..."

**肢体信号**：
- 站姿稍微侧对目标
- 不完全面对她
- 保持一点距离

## E: 执行
1. **开场白 + 理由**：先用间接开场白，同时给出理由
2. **口语时间限制**："我只问一句..." "我马上要走了..."
3. **肢体时间限制**：侧身、摇摆、不完全面对、表现赶时间
4. **最佳效果**：口语+肢体同时使用
5. **后续**：如果互动很好，时间限制到了可以自然延续

## B: 边界
**不适用**：
- 已经熟悉的朋友圈
- 对方明显想继续聊
- 一对一私下场合

**失败模式**：
- 说了时间限制但不走，显得虚伪
- 太早说时间限制打断了好的互动
- 理由太假或不合理
- 肢体语言与言语矛盾
