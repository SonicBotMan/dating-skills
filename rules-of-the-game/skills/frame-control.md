# Frame Control - 框架控制

## R: 原文
> "换句话说，框架就是人们对周围事物的认知情况，你可以塑造框架，让互动达到你希望的结果；也可以改变自己的框架、别人的框架，或捏造框架，让某些对话与情况似乎真的存在。"（第二十二天简报）

> "刚认识一个女人时，一定要有坚强的框架，让她觉得必须寻求你的认同，而非反过来。"（第二十二天简报）

> "弹性最大的人才是主导互动的人。"（引用Robert Dilts）

> "框架重组是改变框架或提供新观点的过程。"（第二十二天简报）

## I: 骨架
1. **框架定义**：人们对周围事物的认知和赋予的意义
2. **核心原则**：永远保持坚强框架，让她进入你的世界
3. **框架类型**：大小、情境、内容、批评者
4. **框架重组**：改变框架而非改变事实
5. **调情本质**：大多数调情就是框架重组
6. **弹性原则**：弹性最大的人主导互动

## A1: 案例
> 场景：女人撞到你
> 错误框架：意外碰撞 → 尴尬道歉
> 正确框架："你刚才摸我屁股吗？" → 性暗示调情

> 场景：女人问"你为什么跟我说话？"
> 错误反应：紧张解释、证明自己、变得防御
> 正确反应："我朋友说你看起来像需要被拯救的样子。" → 幽默重组

> 场景：带女人回家，但她担心朋友看法
> 框架放大：拉远镜头谈人生苦短
> 框架缩小：特写删除朋友，专注她的欲望

## A2: 触发
**使用场景**：
- 任何被质疑或挑战的时刻
- 需要主导对话方向时
- 对方表现出防御姿态

**危机信号**：
- "你为什么跟我说话？"
- "你想要什么？"
- 她开始问太多问题
- 她的朋友试图带走她

**框架重组时机**：
- 批评 → 理解对方出发点
- 负面 → 正面重新诠释
- 限制 → 可能性探索

## E: 执行
1. **保持框架**：不进入她的框架解释自己
2. **重组内容**：检视行为背后的观点和意图
3. **改变大小**：用摄影机比喻放大或缩小框架
4. **重组批评者**：理解批评者的善意
5. **幽默转移**：用幽默化解尴尬
6. **弹性应对**：必要时退让也是胜利

## B: 边界
**不适用**：
- 对方完全封闭无法沟通
- 涉及安全和法律问题
- 对方明显不适用的情境

**失败模式**：
- 过度控制显得固执
- 不观察对方的反应
- 框架太脆弱（乞求、买酒请她）
- 不懂得何时退让
- 框架重组失败后继续硬撑
