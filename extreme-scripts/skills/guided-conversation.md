## R 原文

"我和女人聊天的时候几乎很少发问，惯用的方式是'引导'，我喜欢用'引导'和女人对话，更重要的是，女人们很享受被我用这种方式带领。"

"引导，起得是带动女人的作用，想要正确地使用引导，聊天的时候就必须使用陈述句，对你想要展开的内容进行陈述，同时，尽量减少一些语气助词。"

"引导的核心——'提供话题的方向'"

## I 骨架

**引导 = 陈述句 + 提供话题方向**：
- 不用"吗"结尾的疑问句
- 用"我发现了...""我刚才...""我听说..."开头
- 让女生在你设定的话题里回应

**两种引导形式**：
1. 单一引导：直接提供话题方向
2. 先展示自己再引导：先说自己的事，再把话题抛给她

## A1 案例

**单一引导**：
- "刚才我发现了一个秘密" → 话题会围绕秘密展开
- "最近好像新出了一部电影..." → 话题引向电影
- "和你相处下来，发现你身上有一种很温和的亲和力" → 引向"亲和力"话题

**先展示自己再引导**：
```
男：这个蛋糕好可爱（小黄人）
男：我生日的时候收到DIY的卡通蛋糕
男：我也觉得很可爱，吃起来应该很甜
男：你也收到过类似的礼物吧？（引导对方）
```

**对比**：
- 错误："你喜欢吃什么口味的蛋糕？" → 对方回答就结束
- 正确："这个蛋糕好可爱" → 引发讨论 → "我生日收过DIY的..." → "你呢？"

## A2 触发

"我问她问题她总是不回答或者很敷衍"
"聊天时不知道说什么，总是问一句答一句"

→ 触发：习惯性追问，导致被动聊天

## E 执行

**引导开场**：
- "我刚才看到一件事..." → 引向她可能感兴趣的事
- "我最近发现..." → 引向你的生活
- "你知道吗..." → 引向知识/趣味话题

**引导+展示**：
- "今天去了一家餐厅，它们的招牌菜很好吃"（展示你会吃）
- "这本书让我想到..."（展示你在思考）
- "我小时候..."（展示过去）

**引导话术**：
- "刚才发现一个有意思的事" + 停顿
- "我昨天去了..." + 描述感受
- "你应该也..."（引导她进入你的话题）

**不要这样问**：
- "你吃饭了吗？" → 对方回答"吃了"就死了
- "你多大了？" → 对方回答一个数字就死了
- "你在干嘛？" → 对方回答就死了

## B 边界

- 引导不是自说自话，要留互动空间
- 展示自己要自然，不要像炫耀
- 引导要有方向，不是漫无目的
- 有时还是需要问问题，关键是比例
- 关系早期引导效果最好，后期可以更平等
