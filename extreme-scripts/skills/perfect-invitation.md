## R 原文

"邀约前要判断窗口，找出可以邀约的潜在目标，或进一步可供发展的对象。一般处在无聊状态的目标最好邀约。在无聊的状态下，女人的大脑处于短暂的空白状态，这时候内在的精神状态空虚，需要她们从外界获取精神价值。"

"邀约方式分为两种，一种是模糊邀约，一种是直接邀约。模糊邀约带有一定的试探效果，在你不确定目标是否有很大可能和你出来时，可以使用模糊邀约。"

"女人想要被邀约，有个非常典型的症状隐藏在行为背后，会重复一些行为，或者重复说一些内容，并且从这些内容中你可以感受到，她现在无事可做，试图用这种方式来告诉你，你应该主动邀约她。"

## I 骨架

**完美邀约 = 时机判断 + 方式选择**：
- 时机：无聊状态、重复行为
- 模糊邀约：模式时间空间/模糊时间明确地点/明确时间模糊地点
- 直接邀约：突出地点环境和感觉

## A1 案例

**识别无聊窗口**：
```
女（重复）：我肚子饿了
女（重复）：我肚子饿了
→ 不是真的饿，是无聊信号
→ "那你想吃什么？"
→ 可以顺势邀约
```

**模糊邀约三式**：
```
1. "有时间一起出来转转"（模式时间空间）

2. "欢乐谷的过山车挺有意思的，有时间我们一起过去"（模糊时间明确地点）
   → 她说去 = 继续确定时间

3. "晚上我们一起去转转吧"（明确时间模糊地点）
   → 直接约晚上，看她反应
```

**直接邀约**：
"上周我发现一家很有情调的音乐餐厅，那里的灯光很适合聊天，下次一起去？"
→ 突出地点价值，给她去的理由

## A2 触发

"怎么判断她是不是想被我约"
"约她出来她总是说没空"

→ 触发：不确定邀约时机，或者邀约方式不对

## E 执行

**识别邀约窗口**：
- 她重复说某件事（饿了、想看电影、无聊）
- 聊天气氛好的时候
- 她主动延长对话
- 她问你问题（好奇窗口）

**模糊邀约三式**：

1. **模式时间空间**（最安全）
   - "有空一起出来玩"
   - "改天约个饭"
   - 适用：关系早期，不确定兴趣

2. **模糊时间明确地点**（有方向）
   - "那家日料听说很不错，改天一起去试试？"
   - 适用：知道她的兴趣方向

3. **明确时间模糊地点**（有把握）
   - "这周六有空吗？"
   - 适用：关系不错，了解她的时间

**直接邀约要点**：
- 突出地点的特色和氛围
- 给她去的理由
- 不要说"我想约你"这种暴露意图的话

**邀约后处理**：
- 她同意 → 立即确定时间地点
- 她犹豫 →帮她做决定
- 她拒绝 → "好的，有机会再说"，不强求

## B 边界

- 邀约不能急，要在气氛最高点邀约
- 不要在话题冷的时候邀约
- 被拒后不要追问原因
- 不能连续邀约，被拒说明吸引不够
- 邀约地点要选择她感兴趣的地方
