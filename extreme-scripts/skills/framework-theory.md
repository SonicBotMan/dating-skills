## R 原文

"框架理论（隐含）"：五种框架类型
- 强框架：占据主导地位
- 弱框架：被动接受
- 反框架：逆转主导权
- 隐形框架：隐蔽地引导
- 超级框架：多重叠加

"在聊天初期的关系设置也非常的重要，女生会从前期你对她的态度，来决定她对你的态度。之所以有女神，就是因为有屌丝回去跪舔。那么最好的方式是你的态度要高于女生一些，这里涉及到了如何建立设立框架的话术技巧。"

## I 骨架

**框架 = 对话中的权力结构**：
- 强框架：我是主角，你是配角
- 弱框架：你是主角，我是配角
- 反框架：逆转当前权力关系
- 隐形框架：不显山露水地引导
- 超级框架：表面弱势实际主导

**框架博弈**：谁的框架更强，谁就主导对话

## A1 案例

**强框架**：
男：过来给我按按摩
女：为什么
男：因为我今天累了，你是贴心小棉袄
→ 强势要求，但包装成调侃

**弱框架转反框架**：
女：你是不是对谁都这样
男：只对有意思的人这样，你很有趣
→ 把弱框架（被质疑）转成奖品框架（你很有趣才配得上）

**隐形框架**：
男：你想吃什么
女：随便
男：那就吃火锅吧，我知道一家很不错的店
→ 看似尊重对方选择，实际是早就决定好的

**对话中的框架切换**：
```
女：你觉得我漂亮吗
普通回答：漂亮啊（弱框架）
强框架回答：漂亮是漂亮，但我更在意你是不是有趣（高标准）
反框架回答：你觉得我帅吗（逆转）
```

## A2 触发

"她总是对我呼来喝去"
"我感觉自己在一味讨好她"

→ 触发：框架失衡，关系中处于弱势

## E 执行

**建立强框架**：
- 不要问"行不行"，直接说"这样做"
- 减少疑问语气，多用陈述句
- 设置框架："我喜欢的女生是这样的..."

**反框架技巧**：
- 被质疑时："你这样问，是因为你对我感兴趣吗"
- 被打压时："你觉得我应该怎么改进？"（把球踢回去）
- 被测试时：用幽默化解，不正面回答

**隐形框架**：
- 让她觉得是她自己在做决定
- 提供两个选项，都是你想要的结果
- 问"为什么"让她自己说服自己

**框架维护**：
- 被挑战时不要慌张，这是测试
- 保持一致性，不能前后矛盾
- 框架要有弹性，不能太硬

## B 边界

- 框架太硬会显得傲慢
- 刚认识时不要用太强硬的框架
- 框架要根据关系阶段调整
- 女性会测试框架，保持稳定即可
- 框架不是操控，是保持自我价值
