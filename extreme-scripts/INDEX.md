# 极限话术 - 技能索引

## 总览
本书提供系统化的对话思维框架，核心理念：思维>话术，不背惯例，而是掌握对话的底层逻辑。

## 技能列表

### 1. cross-dialogue-thinking
十字纵横对话思维
通过横向展开（多角度接话）和纵向深入（挖掘细节）来扩展对话内容的思维方式。利用关键词分类和图像生成，让话题源源不断。

### 2. guided-conversation
引导式聊天
用陈述句代替疑问句来引导话题方向，让女生跟随着你的话题走，而不是被她的问题牵着鼻子走。

### 3. logical-trap-setting
逻辑陷阱设置
利用词汇的双重含义制造逻辑陷阱，让对方在不知不觉中进入你设定的逻辑框架。

### 4. framework-theory
框架理论
框架是谈话中的权力结构，决定谁主导谁跟随。通过强框架、弱框架、反框架、隐形框架的切换掌握主动权。

### 5. shit-test-coping
打压测试应对
女生通过各种测试（打压、筛选、服从、性暗示等）来评估男性价值。识别测试类型并用对应框架策略回应。

### 6. perfect-invitation
完美邀约
在最佳时机用最佳方式邀请女生出来，包含时机判断、模糊邀约三式和直接邀约的技巧。

## 核心框架

1. **十字纵横法**：横向展开+纵向深入+图像生成
2. **引导>追问**：陈述句带领话题
3. **框架博弈**：强框架/弱框架/反框架/隐形框架
4. **打压测试应对**：十种测试类型及反制策略
