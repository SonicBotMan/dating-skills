## R 原文

"找个机会和对方一起喝饮料的机会，闲聊一会儿之后，假装不经意地把自己的杯子移近对方的杯子，如果对方没有移动杯子的话，就可以说明两人的距离感缩短了。如果对方又默默把杯子移开的话，就表示他觉得两人还是维持现状就好，没有进一步的打算。"

"透过杯子间的距离，就可测知两人的距离。别小看这简单的技巧，请试试看，还蛮准的哦！"

## I 骨架

**杯子技巧 = 物理距离测试**：
- 移近杯子 → 测试是否接受靠近
- 不动 → 接受现状
- 移开 → 拒绝靠近

**场景**：约会、咖啡厅、酒吧、聚会

## A1 案例

**第一次约会**：
```
男：点两杯咖啡，找个安静的角落坐下
（聊天进行10分钟后）

男：（假装不经意地把自己的咖啡杯往她方向推了一点）
女：（没有动，继续说话）
→ 她接受了靠近，可以进一步

男：（再过一会儿，又把杯子推近一点）
女：（犹豫了一下，默默把杯子移回原位）
→ 她不想再靠近，保持现有距离
```

**酒吧场景**：
```
男：请她喝一杯
（几分钟后）

男：（自然地把酒杯往她方向移）
女：（主动把自己的酒杯碰过来）
→ 她有意靠近
```

## A2 触发

"我怎么知道她对我有没有意思"
"约会的时候怎么判断能不能更进一步"

→ 触发：需要隐蔽地测试对方兴趣

## E 执行

**操作步骤**：
1. 选择一个自然的场景（喝东西时）
2. 聊天进行10-15分钟后开始
3. 假装不经意地把杯子往她方向推一点
4. 观察她的反应（30秒内）

**结果解读**：
- 她没动杯子 → 接受，可以继续
- 她移开杯子 → 拒绝，不要再推进
- 她把杯子也移近 → 很大兴趣，可以大胆

**进阶用法**：
- 可以用手指、餐巾纸等代替杯子
- 可以在走路时故意靠近一点
- 可以在坐车时调整座位距离

## B 边界

- 不要连续测试，两次就够了
- 动作要自然，不能刻意
- 测试失败后不要强行继续
- 要结合其他信号综合判断
- 不能在公共场合让她尴尬
