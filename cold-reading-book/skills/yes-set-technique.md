## R 原文

"Yes-set 肯定组合：连续肯定建立积极氛围。问对方会回答'是'的问题，连续3-5个肯定后提出真正请求。"

## I 骨架

**Yes-set = 连续肯定 → 建立顺从惯性**：
1. 问3-5个对方会说"是"的问题
2. 对方进入"说是"模式
3. 提出真正请求
4. 对方惯性接受

## A1 案例

**场景：邀请对方参加活动**：
```
你：你喜欢听音乐吗？ → 是
你：喜欢在轻松的环境下听？ → 是
你：如果有个地方音乐很棒，你会想去吗？ → 是
你：那周六晚上我们一起去那家爵士酒吧？ → 好啊
```

**场景：请求帮助**：
```
你：你在忙吗？ → 没有
你：这个事情对你来说应该不难？ → 应该不难
你：你能帮我看一下吗？ → 好啊
```

**失败的Yes-set**：
```
你：你讨厌加班吗？ → 是（这个NO会影响后面）
你：那你愿意帮我加班吗？ → 不...
```

## A2 触发

"我提要求她总是拒绝"
"怎么让她更容易答应我"

→ 触发：需要让对方在不抗拒的情况下接受请求

## E 执行

**Yes-set设计原则**：
- 前置问题必须是对方肯定会说"是"的
- 问题要简单，不需要思考
- 3-5个"是"之后提真正请求
- 最后一个问题和请求要有逻辑关联

**问题类型**：
- 事实型："你喜欢...对吧？" → 对方认同
- 推测型："你应该也会...对吧？" → 对方认可
- 选择型："你比较喜欢oxx还是oxx？" → 无论选哪个都是"是"

**Yes-set后的请求**：
- 要自然，不要太突兀
- 不要太复杂，越简单越好
- 给她台阶："如果不行也没关系"

## B 边界

- 对方如果状态不好会失效
- 不能频繁使用，会被识破
- 紧急情况不要用，来不及铺垫
- 真诚是基础，套路不能代替真心
- 只适合请求，不适合重大决定
