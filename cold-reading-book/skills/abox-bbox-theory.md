## R 原文

"A-Box（潜意识）：储存原始信息，不加筛选
B-Box（显意识）：筛选处理接收到的信息"

"在冷读过程中，看起来读心者能够说中咨询者现在和过去发生的事，推测出他内心的想法，并能预测他的未来。但其实，与其说这是'读心者知道咨询者的一切'，不如说是'读心者让咨询者相信他所说的一切'比较正确。"

## I 骨架

**A-Box/B-Box理论的核心**：
- A-Box = 潜意识，直接反应，不筛选
- B-Box = 显意识，逻辑筛选，处理信息
- 冷读 = 让B-Box自己填补空白

**冷读的原理**：不是说出真相，而是让对方相信你说的是真相

## A1 案例

**传统询问**：
```
你：你最近是不是有什么烦恼？
她：我没有啊
→ 直接问，对方会否认
```

**冷读方式**：
```
我：你最近可能有些事情让你有点烦恼，但你不是那种会轻易说出来的人
她：...你怎么知道
→ 不直接问，让她在"不否认自己"的前提下接受暗示
```

**A-Box和B-Box的区别**：
```
A-Box反应：你说的这个不对
B-Box反应：她好像真的了解我

当B-Box开始工作时，她会开始找证据证明"她说的对"
```

## A2 触发

"为什么冷读有时候不生效"
"她为什么总是否认我说的"

→ 触发：直接询问被否认，需要绕道而行

## E 执行

**直接vs冷读对比**：
- 直接："你是不是不开心" → 对方否认
- 冷读："你表面上看起来很平静，但我感觉得到..." → 对方不否认，因为你没有直接问

**冷读流程**：
1. 建立初步信任
2. 给出模糊的"洞察"
3. 观察反应（微表情、肢体语言）
4. 调整/确认

**给B-Box工作的方式**：
- "你应该是..."（推测性语气）
- "我有种感觉..."
- "我不太确定，但..."

**让对方自己填补**：
- "你好像在oxx方面有特别的想法" → 对方会自己说出来
- "你可能经历过oxx" → 对方会回忆并确认

## B 边界

- 不信任的环境下冷读无效
- 对方逻辑性太强可能会分析而不是接受
- 不能用在已经被验证过的事实上
- 冷读需要一定的信任基础
- 不能过度依赖，要结合真实观察
