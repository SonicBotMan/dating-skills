## R 原文

"同调言行：模仿对方语言模式建立亲和感"

## I 骨架

**镜像/同调的核心**：潜意识喜欢和自己相似的人
- 肢体语言同步
- 语速语调模仿
- 呼吸节奏同步
- 用词习惯匹配

## A1 案例

**语速同步**：
```
她说话很快 → 你也稍微加快
她说话很慢 → 你也放慢语速
→ 她会感觉你"很懂她"
```

**肢体同步**：
```
她身体前倾 → 你也微微前倾
她翘起二郎腿 → 你也调整姿势
她摸了下耳朵 → 稍后你也自然地碰一下耳朵
→ 她不知道自己为什么会放松，但会感觉舒适
```

**用词同步**：
```
她用"超喜欢" → 你也说"超..."
她用"感觉" → 你也说"感觉..."
她用书面语 → 你也调整措辞
```

## A2 触发

"她总是对我有防备"
"我怎么让她感觉更亲近"

→ 触发：需要建立信任和亲和感

## E 执行

**三个层次的同步**：

**1. 肢体同步**：
- 坐姿/站姿
- 手的动作
- 身体倾斜角度
- 呼吸节奏

**2. 语言同步**：
- 语速
- 语调
- 用词选择
- 口头禅

**3. 情绪同步**：
- 她开心时你也开心
- 她认真时你也认真
- 她激动时你表现出理解

**注意事项**：
- 延迟0.5-1秒再同步，不能立即模仿
- 只同步一部分，不要全套复制
- 自然地同步，不要让她发现你在模仿

## B 边界

- 不要立即同步，要有延迟
- 不要100%复制，太刻意
- 只能在信任建立初期使用
- 不是操控，是建立亲和
- 过了这个阶段可以停止同步
