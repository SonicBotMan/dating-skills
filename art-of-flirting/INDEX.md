# 调情的艺术 - 技能索引

## 核心技能 (Core Skills)

### art-of-flirting
调情的艺术是一门关于两性吸引的心理学著作，从科学角度分析了调情背后的心理机制。
- **框架**: 外貌 + 肢体语言 + 自我价值 + 好感机制
- **适合场景**: 调情基础、两性吸引

### reading-body-language-in-flirting
通过解读肢体语言判断兴趣和好感，是调情中的核心观察技能。
- **框架**: 目光接触 + 身体朝向 + 空间距离 + 姿态 + 触摸行为
- **适合场景**: 初次相遇、约会、任何调情场合

### appearance-charm
外貌作为调情的第一张名片，在5秒内形成第一印象，但核心原则是自信比漂亮更重要。
- **框架**: 漂亮就是好的效应 + 身高 + 着装
- **适合场景**: 第一印象、形象管理

## 进阶技能 (Advanced Skills)

### self-worth-confidence
自我价值是调情成功的心理基础，关键不是漂亮而是自认为漂亮。
- **框架**: 自我认知 + 自信建立 + 自卑应对
- **适合场景**: 自我提升、心态调整

### language-voice
声音和语言是调情中的重要工具，热情洋溢的声音令人心动。
- **框架**: 声音感染力 + 语调 + 语言优美
- **适合场景**: 面对面交流、电话聊天

### psychology-of-attraction
好感的起因分析了好感是如何产生的，包括优势、公平、相似性等机制。
- **框架**: 优势赢得好感 + 公平理论 + 相似性
- **适合场景**: 理解吸引机制

### special-effects
特殊效应是指调情过程中影响魅力感知的心理效应。
- **框架**: 反衬效应 + 兴奋误判 + 时间效应
- **适合场景**: 约会环境选择、时机把握

## 核心框架

### 外貌与魅力
- "漂亮的就是好的"：有魅力的人被认为更睿智、更有趣
- 美就是"普通"：平均脸型更具吸引力
- 身高对男性更重要
- 着装体现地位和性信号

### 肢体语言
- 70%交际是非言语性的
- 自信者拥有更丰富的肢体语言
- 四种间距：亲密型、个人型、社会型、公开型
- 走姿透露性信号

### 好感起因
- 真诚的赞扬
- 公平投入
- 相似性
- 难以征服者更让人仰慕

### 自我价值
- 关键不是漂亮而是自认为漂亮
- 自信的人更善于解读肢体语言
- 自卑者发出模糊的双重信号

### 语言与声音
- 声音传递情感
- 语调改变语义
- 相同方言营造亲近感

### 特殊效应
- 反衬效应：周围高魅力人群降低对普通人的评价
- 兴奋误判：生理兴奋被感知为性吸引
- 投资效应：投入越多，魅力评价越高
