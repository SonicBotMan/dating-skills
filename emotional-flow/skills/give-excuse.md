# R原文

> "人不喜欢被强迫，但喜欢被说服。给台阶是一种艺术，核心是让对方有理由接受你的请求，而不失面子。技巧是：先说一个合理的理由，再说一个补偿，最后给一个正向的框架。让她觉得接受你的请求是她的选择，而不是被迫。"

# I骨架

**给台阶**是一种让对方有理由接受的技术：

| 部分 | 内容 | 示例 |
|------|------|------|
| 理由 | 解释为什么 | "因为你帮了我很多" |
| 补偿 | 她能得到什么 | "下次我请你吃饭" |
| 正向框架 | 这是她的选择 | "我相信你会的" |

关键：理由要合理，补偿要具体，框架要正向

# A1案例

**场景**：你想让她陪你参加聚会

糟糕："你必须陪我去。"
好："我知道你对这些不感兴趣（理由），但有你在我会安心很多（补偿）。而且你会见到我那群有趣的朋友，说不定会有惊喜（正向框架）。"

**要电话号码时**：
"我很想再见到你（理由），你给我你的号码吧，下次我带你去那家咖啡馆（补偿）。你不会给陌生人号码对吧？（正向框架：她会说"那要看情况"）"

# A2触发场景

触发点：对方似乎在犹豫；你需要她做某件事；她需要一个理由

练习：下次请人帮忙时，用"因为...所以..."的句式

# E执行步骤

1. 说一个她能接受的理由
2. 说她能得到什么（补偿）
3. 给一个正向的框架
4. 让她觉得这是她的选择
5. 等待她的回应

# B边界

不要：理由太假；强迫她；补偿太明显是贿赂
