# R原文

> "深度对话不是一下子建立的，它需要从浅到深一层层递进。每个层次都是下一个的基础。跳过层次就像跳过楼梯的台阶——你可以，但你会摔跤。六个层次是：1寒暄→2事实→3观点→4感受→5需求→6秘密。"

# I骨架

**六步对话递进**是从浅到深建立连接的路径。

| 层次 | 内容 | 示例 |
|------|------|------|
| 1 | 寒暄 | 今天天气真好 |
| 2 | 事实 | 我每天早上跑步 |
| 3 | 观点 | 我觉得早起改变了我 |
| 4 | 感受 | 跑步让我感到自由 |
| 5 | 需求 | 我需要属于自己的时间 |
| 6 | 秘密 | 其实我经常感到孤独 |

原则：
- 每个层次是下一步的基础
- 不能跳过
- 可以同时谈几个话题，但深度要对应

# A1案例

**递进示例**：
```
1寒暄：最近忙吗？
2事实：我最近在准备一个考试。
3观点：我觉得这个考试其实没什么用。
4感受：但为了工作又不得不考，有点无奈。
5需求：我其实更想花时间学点真正感兴趣的东西。
6秘密：说实话，我有时候不知道自己要什么。
```

# A2触发场景

触发点：对话只停留在表面；你想建立更深关系；对方愿意继续聊

如何判断：她愿意回答你的追问；她也问你问题；她分享自己的事

# E执行步骤

1. 从当前层次开始，不要急着深挖
2. 对方回应后，自然地向下深入一层
3. 如果她停住：在同一层多聊一会
4. 注意她的意愿：她准备好深聊了吗？
5. 不要审讯：分享自己的同时引导她

# B边界

不要：跳过中间层次；一次问到底；不分享自己只问她
