# R原文

> "情绪本身并不复杂，复杂的是我们不知道自己想要什么。我们习惯性地逃避自己的真实感受，用忙碌来麻痹，用分析来回避。但真正的问题不是情绪本身，而是我们不认识它们。认识情绪的第一步，是学会三层提问：这是什么情绪？为什么会产生这个情绪？我可以做些什么？"

# I骨架

**自我认知三步法**是一种认识自己情绪的工具，核心是三层递进提问。

| 层级 | 问题 | 目的 |
|------|------|------|
| 第一层 | 这是什么情绪？ | 命名情绪（开心、愤怒、恐惧、悲伤） |
| 第二层 | 为什么会有这个情绪？ | 找到触发点 |
| 第三层 | 我可以做什么？ | 采取行动或接受 |

# A1案例

**场景**：你被朋友当众取笑，感到不舒服

1. **这是什么情绪？** → 愤怒，还有一点尴尬
2. **为什么会有？** → 因为我感觉不被尊重
3. **我可以做什么？** → 
   - 选择当时反击
   - 事后私下沟通
   - 接受它然后放下

# A2触发场景

触发点：感到情绪波动时；对自己反应困惑时；想更了解自己时

工具：写下来；说出来；对镜问自己

# E执行步骤

1. 停下来：感到情绪时先暂停
2. 命名：我在感到___（具体情绪词）
3. 追溯：是因为___（触发事件）
4. 选择：现在我可以___（选项）
5. 行动：选择一个行动

# B边界

不要：跳过第一层直接分析原因；否认情绪存在；停留在分析不行动
