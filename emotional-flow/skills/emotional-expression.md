# R原文

> "情绪表达不是发泄，而是在尊重自己感受的同时，也让对方能够理解你。有效的情绪表达有三个步骤：第一步，用精确的词命名情绪。第二步，说明触发这个情绪的具体事件。第三步，表达你的需求或者请求。做到这三点，对方就不会觉得被指责，而是感到被理解。"

# I骨架

**情绪表达**的三个步骤：

| 步骤 | 内容 | 示例 |
|------|------|------|
| 1. 命名 | 用精确的情绪词 | "我感到失落" |
| 2. 事件 | 具体触发的事 | "因为你没有回我消息" |
| 3. 请求 | 你希望怎样 | "我希望你能告诉我你在忙" |

关键：不用"你让我..."（指责），用"我感到..."（自我负责）

# A1案例

**糟糕的表达**：
"你为什么总是不回我消息？你就是不在乎我！"

→ 指责，对方防御

**有效的表达**：
"我感到很担心（命名），因为你没有回我消息（事件）。我希望你能告诉我你在忙（请求）。"

→ 对方愿意回应，而不是防御

# A2触发场景

触发点：你想表达不满时；需要让对方理解你时；避免冲突时

练习：先用"我感到..."句子，再用"你让我..."句子，体会区别

# E执行步骤

1. 命名情绪：精确的词，不是"很糟糕"
2. 描述事件：具体的事情，不是泛泛的指责
3. 表达请求：具体可做的，不是"你要对我好一点"
4. 注意语气：平静陈述，不是责备
5. 给对方回应空间

# B边界

不要：情绪爆发时表达；在对方也情绪化时表达；用情绪表达控制对方
