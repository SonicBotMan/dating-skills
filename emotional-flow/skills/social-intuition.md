# R原文

> "社交直觉不是一项单一技能，而是所有情绪能力的综合应用。当你能够准确读懂对方的情绪，用恰当的方式表达自己，并能根据情境调整回应，你就有了社交直觉。它让你在合适的时机说合适的话，在别人还没反应过来时你已经知道该怎么做了。"

# I骨架

**社交直觉**是多种情绪能力的综合：

| 组成能力 | 作用 |
|---------|------|
| 情绪认知 | 知道现在发生了什么情绪 |
| 情绪判断 | 读懂对方的真实情绪 |
| 情绪表达 | 用恰当方式表达自己 |
| 情境判断 | 知道什么行为是合适的 |

判断标准：
- 对方放松还是紧张？
- 她需要空间还是连接？
- 现在适合深入还是保持轻松？

# A1案例

**场景**：聚会中有人讲了冒犯的话

没有直觉的人：生气怼回去或假装没听到

有直觉的人：
1. 读懂：那个人可能不是故意的，被冒犯的人有点尴尬
2. 判断：大多数人不觉得是大事，但被冒犯的人需要台阶
3. 回应：用一句轻松的话化解尴尬，不让任何人丢面子

→ 得体而不是过度反应

# A2触发场景

触发点：复杂社交场合；需要快速判断时；不确定该怎么做时

练习：观察一个社交场景，试着读懂每个人的情绪和立场

# E执行步骤

1. 停下来：不要急着反应
2. 观察：现在每个人是什么情绪状态？
3. 判断：谁需要什么？
4. 回应：什么样的行为是恰当的？
5. 复盘：结束后回想哪里做得好，哪里可以改进

# B边界

不要：过度分析；太慢反应；忽略自己的感受
