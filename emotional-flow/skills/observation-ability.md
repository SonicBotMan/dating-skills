# R原文

> "观察不是天赋，是习惯。大多数人看过就忘，是因为他们没有刻意训练。观察的第一步是有意识地去看。第二步是有意识地记住。第三步是有意识地联系。做到这三点，你就能从'没注意到'到'注意到并记住'。"

# I骨架

**观察能力**是三项技能的组合：
1. **看到**：有意识地注意细节
2. **记住**：不只看过，要记住
3. **联系**：把观察到的信息串联起来

训练方法：
- 每天选一个人观察3个细节
- 记住一个人的3个特征，下次认出她
- 观察一个人的表情变化，推断情绪

# A1案例

**场景**：你刚认识一个人

1. **看到**：她的包上有个小挂件；她的指甲油是蓝色；她笑起来有个酒窝
2. **记住**：下次见面记得这些细节
3. **联系**：包上的挂件可能是她喜欢的品牌；蓝色指甲油说明她有个性；酒窝让她的笑很特别

→ 你比大多数人都更了解她

# A2触发场景

触发点：认识新朋友时；等人时；坐地铁时

练习：
- 每天观察3个陌生人，各记3个细节
- 看照片时注意背景、表情、姿势
- 回忆昨天见到的人的穿着

# E执行步骤

1. 设定提醒：每天固定时间练习
2. 选择观察对象：一个人开始
3. 记住3个细节：穿着、配饰、表情、姿态
4. 复述给自己听：加强记忆
5. 复盘：睡前回忆今天观察到的人

# B边界

不要：盯着人看不礼貌；过度解读；记住负面细节
