# R原文

> "长期关系不是一时激情，而是持续的投入和理解。关键两个概念：情绪存款和冲突理解。情绪存款是在平时多存'好情绪'，让关系有安全垫。冲突理解是知道冲突不可避免，但冲突本身不是问题，问题是处理冲突的方式。"

# I骨架

**长期关系**的两个核心：

**情绪存款**：
- 平时多表达欣赏、感谢、关心
- 让她知道你在乎她
- 小的日常举动 > 大的特殊时刻

**冲突处理**：
- 冲突不可避免
- 冲突本身不是问题
- 问题=冲突+处理方式
- 温和讨论 > 冷战 > 爆发

# A1案例

**情绪存款示例**：
- "谢谢你在背后支持我"（感谢）
- "你知道吗，和你在一起我很安心"（欣赏）
- "我看到你最近很辛苦，有我能帮忙的吗"（关心）

**冲突处理示例**：
```
坏：冷战（不说、不理）
中：争吵（情绪爆发）
好："我觉得...我希望你...能不能..."（温和表达）
```

# A2触发场景

触发点：关系进入稳定期；出现矛盾时；想让关系更深入时

练习：每周做一次"情绪存款"：说一件你感谢她的事

# E执行步骤

1. 平时多表达：感谢、欣赏、关心
2. 不要等到需要时才说
3. 冲突时：先暂停，等冷静
4. 用"我感到...因为..."表达
5. 一起找解决方案，不是争对错

# B边界

不要：只有需要时才联系；冲突时人身攻击；忽视小问题
