# R原文

> "很多人争论对错，却忘了你们看到的世界本来就不同。站在对方角度，不是要你同意她，而是理解她为什么这么想。当你理解了，她的观点就不再是'无理取闹'，而是'一种合理的存在'。这是情商的核心。"

# I骨架

**换位思考**是从对方视角看问题的能力，核心是理解"为什么"而不是判断"对错"。

练习步骤：
1. 陈述对方的观点（不评判）
2. 找到她形成这个观点的原因
3. 想象她的处境和经历
4. 理解她的情绪反应

关键：理解≠同意

# A1案例

**场景**：朋友说"我不想工作了"

```
表面观点：不想工作
原因：可能是累了；可能被老板伤了；可能找不到意义

换位理解：
"我理解你最近压力很大，每天加班到很晚，换谁都会累。你不是真的不想工作，只是不想像现在这样工作。"
```

→ 你说中了她的感受，而不是她的表面话语

# A2触发场景

触发点：对方观点让你不解；你想更好理解她；争论即将发生

练习：听到让你不认同的观点时，先问"她经历了什么才会这么想？"

# E执行步骤

1. 暂停判断：先不说是对是错
2. 陈述对方观点："你的意思是..."
3. 追溯原因："是因为..."
4. 表达理解："我理解你..."
5. 然后再说你的观点

# B边界

不要：理解=同意；为了理解而放弃自己立场；假装理解
