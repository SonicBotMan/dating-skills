# R原文

> "注视是一种艺术，不是审视。区别在于，注视是温暖的，审视是冰冷的。正确的注视节奏是：看——停——给。看三秒，停顿一下，给一个微笑或者一个小动作。持续盯着人看会让人不舒服，但适度的注视会让人感到被关注和被重视。"

# I骨架

**凝视技巧**是一种节奏控制，核心是"看-停-给"。

| 步骤 | 时长 | 内容 |
|------|------|------|
| 看 | 2-3秒 | 温柔地看着她的眼睛 |
| 停 | 1秒 | 停顿，不要盯着不放 |
| 给 | - | 微笑、点头、或说一句话 |

效果：
- 被关注而不是被审视
- 温暖而不是侵略性
- 让她放松而不是紧张

# A1案例

**场景**：对话中

```
你：（看着她说）你笑起来真好看。
你：（停顿2秒）
你：（微笑）我打赌你小时候是个调皮的孩子。
```

**错误做法**：
- 一直盯着看，不停顿 → 她会紧张
- 看一眼马上移开 → 不真诚
- 盯着敏感部位看 → 不尊重

# A2触发场景

触发点：对话中需要建立连接时；你想让她感到特别时；想让气氛更亲密时

练习：和朋友练习"看-停-给"的节奏

# E执行步骤

1. 看：目光接触，保持温柔
2. 停：2-3秒后自然停顿
3. 给：微笑、点头、或一句话
4. 重复这个节奏
5. 观察她的反应，调整节奏

# B边界

不要：盯着敏感部位；连续盯超过5秒；眼神冷冰
