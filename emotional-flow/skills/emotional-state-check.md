# R原文

> "情绪判断的第一步是观察，而不是询问。很多人以为了解情绪需要问对方，但最准确的信息来自观察。对方嘴上说'我没事'，但她的表情、语气、身体姿态都在告诉你真相。学会同时观察多个维度，而不是只听语言。"

# I骨架

**情绪状态判断**的核心是多个维度的观察，而不是单一信号。

四个观察维度：
1. **表情**：眼神、眉毛、嘴角
2. **语气**：音调、语速、停顿
3. **肢体**：姿势、动作、距离
4. **呼吸**：快慢、深浅

一致性和矛盾：
- 语言和身体一致 = 真情实感
- 语言和身体矛盾 = 需深入了解

# A1案例

**观察示例**：
- 嘴上说"随便"，但身体后仰、双手抱胸 → 其实不是随便
- 说"很开心认识你"，但眼神飘忽、手在玩东西 → 可能是客套
- 说"我没事"，但声音发紧、眼神闪躲 → 明显有事

# A2触发场景

触发点：对方说一套做一套；你想知道真实想法；对话变得表面

练习：看电视剧时关掉声音，只看画面猜角色情绪

# E执行步骤

1. 同时观察多个维度（至少2-3个）
2. 问自己：语言和身体一致吗？
3. 如果矛盾：她的真实情绪是什么？
4. 根据判断调整回应
5. 不确定时：不要假设，直接温和询问

# B边界

不要：只凭单一信号判断；过度解读；假设你知道她的感受
