# R原文

> "人的行为背后都有情感需求。当你知道对方的需求是什么，你就能理解她的反应，也能知道该怎么回应。基本的情感需求包括被认可、被理解、被尊重、被关注、被接纳、被爱。理解这些需求，你就能看穿很多看似无理取闹的行为。"

# I骨架

**人类基本情感需求**：

| 需求 | 表现 | 当需求未被满足时 |
|------|------|-----------------|
| 被认可 | 希望被肯定 | 过度解释自己 |
| 被理解 | 希望被读懂 | 反复述说同一件事 |
| 被尊重 | 希望被重视 | 表现出防御 |
| 被关注 | 希望被看见 | 做出夸张行为 |
| 被接纳 | 希望被接受 | 隐藏真实自己 |
| 被爱 | 希望被在乎 | 不断确认关系 |

# A1案例

**场景**：女朋友突然不理你

常规反应：她怎么这么无理取闹？

需求视角：
- 她最近压力大，你需要关注她
- 或者她觉得你不够在乎她
- 或者她害怕失去你

→ 不是"无理取闹"，是她有需求没有被满足

# A2触发场景

触发点：对方反应超出预期；她反复做同一件事；你想更深理解她

练习：看到一个"无理取闹"的行为时，问"她哪个需求没有被满足？"

# E执行步骤

1. 观察对方的行为和情绪
2. 问自己：她可能在需求什么？
3. 尝试满足她的核心需求
4. 如果不确定：直接问"我希望怎么做？"
5. 同时表达你的需求

# B边界

不要：认为她的需求不重要；用这个分析来控制她；忽略你自己的需求
