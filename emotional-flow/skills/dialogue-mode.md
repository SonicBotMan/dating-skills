# R原文

> "对话不只是交换信息，更重要的是交换情绪。人们常犯的错误是用信息交换模式去处理情感问题。当对方说'我很难过'，她在寻求情感连接，而不是解决方案。你需要学会判断当前需要哪种模式，并相应调整。"

# I骨架

**对话模式**有两种，根据场景切换：

| 模式 | 什么时候用 | 怎么做 |
|------|-----------|--------|
| 信息交换型 | 讨论事实、决定、计划 | 清晰、直接、有效率 |
| 情感连接型 | 分享感受、寻求理解 | 倾听、共情、不给建议 |

判断方法：
- 对方问"你觉得怎么办"→信息交换
- 对方说"我感到..."→情感连接
- 对方沉默、叹气→情感连接

# A1案例

**错误模式切换**：
```
她：今天被老板骂了，好难过...
他：那你应该怎么做？要不下次注意一点？
她：...（更难过）
```
→ 他用了信息交换来处理情感问题

**正确模式切换**：
```
她：今天被老板骂了，好难过...
他：唉，被骂了肯定不舒服。说说发生了什么？
她：...
他：是啊，换我也会难过。
```

# A2触发场景

触发点：对方分享感受时；对话变得低效时；你想建立更深连接时

练习：对方说事后，先问"你想听建议还是只是想说说？"

# E执行步骤

1. 听对方说什么，判断模式
2. 如果是情感连接：先共情，不给建议
3. 如果是信息交换：直接给信息
4. 情感连接时：复述她说的，显示你在听
5. 模式可以切换：根据对话发展调整

# B边界

不要：在情感连接时给建议；在信息交换时只共情
