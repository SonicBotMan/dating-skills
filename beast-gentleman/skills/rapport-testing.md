# Skill 14: rapport-testing — 确认默契测试

## R — 原文引用（≤150字）

> "确认默契不但能展示'好奇，但无需求'的心态，同时还能测验她的IOI是否为假性，是互动阶段升级关系的最优解决方案。辨别真伪IOI最佳的方式是'确认默契'，比如让她帮忙拎一下东西，让她跟你玩个游戏，看看对方是否愿意投入默契。如果对方并不投入默契，或者投入度不高，那么之前的IOI可以被当作是假IOI。"

## I — 骨架（5-15行）

1. **核心原理**：
   - 默契是吸引的必然结果
   - 确认默契验证IOI真伪
   - 展示"好奇但无需求"心态

2. **默契表现形式**：
   - 认同感：她是否认可你的观点/行为
   - 倾听：她是否愿意认真听你说话
   - 回答问题：她是否重视你的问题
   - 积极提供话题：她是否主动延续对话

3. **默契与抗拒处理**：
   - 配合 → 视为强烈IOI，间歇性回应（7:3比例）
   - 抗拒 → 降低预期，重新激活吸引力开关

4. **递进原则**：
   - 从最小投入开始（让她递个东西）
   - 逐步增加投入（玩游戏→身体接触）
   - 被拒绝立即退回，不强行推进

## A1 — 书中案例

**案例：走路时的默契测试**
你下意识触碰她手臂，示意让她走到另一侧：
- 她欣然接受 → 初步信任，愿意与你达成默契
- 她抗拒 → 你对亲密程度存在误读，需降低预期

**案例：假性IOI识别**
社交经验丰富的女性可能伪装IOI：
- 让她帮忙拎东西 / 让她跟你玩个游戏
- 不投入或投入度不高 → 之前的IOI是假IOI
- 继续努力，重新启动吸引力开关

**7:3回应比例**：
- 她配合你的测试 → 给予正反馈
- 但不要每次都回应，让她期待下一次
- 制造不确定性，让关系更特别

## A2 — 触发场景与语言信号

**触发场景**：
- 收到3-5个IOI后，考虑升级关系前
- 需要验证对方兴趣真假
- 约会中需要确认关系进展程度

**默契测试示例**：
- 让她帮忙拿东西
- 提议玩一个小游戏
- 邀请她跟你转场到下一个地点
- 触碰她手臂测试反应

**抗拒信号**：
- 她拒绝配合你的小请求
- 她表现得冷漠或不耐烦
- 她不回应你的话题延续

**配合信号**：
- 身体朝向你
- 愿意倾听和回应
- 主动提供话题

## E — 可执行步骤

1. **测试前准备**：
   - 确认已收到3-5个IOI
   - 选择最小的默契测试开始
   - 准备好被拒绝的心理预期

2. **执行测试**：
   - 最小测试："帮我拿一下这个"
   - 中等测试："我们来玩个游戏"
   - 进阶测试：转场邀请 / 身体接触

3. **结果判断**：
   - 配合 → 视为真实IOI，进入下一阶段
   - 抗拒 → 退回，重新激活吸引力开关
   - 部分配合 → 维持在当前阶段

4. **间歇性回应**：
   - 配合后给予正反馈（"你真可爱"）
   - 但不要每次都回应
   - 让她期待下一次默契确认

## B — 边界

- **适用边界**：18-35岁男性，适用于约会/互动阶段
- **理论边界**：基于"默契模型"，默契是吸引的必然结果而非控制手段
- **情境边界**：需要先建立足够吸引；没有吸引时确认默契毫无意义
- **危险边界**：不要从大投入开始，被拒绝会伤害关系；不要把默契当控制
- **伦理边界**：默契是双方自愿的投入，不是强迫或操纵
