# Skill 11: text-messaging-rules — 短信互动八法则

## R — 原文引用（≤150字）

> "千万不要闷头不停地和刚认识的女人聊天，你们之间的互动需要有很好的节奏。控制一下自己，别一头栽进去。这八个建议会对你很有帮助：①不要问问题；②避免聊家常；③只聊你们之间的事情；④表情能帮大忙；⑤像幼儿园小孩一样对话；⑥不要在不见面的情况下升级关系；⑦见好就收；⑧注意间隔和时间。"

## I — 骨架（5-15行）

1. **不要问问题**：查户口式提问让人反感，没话题宁可沉默
2. **避免聊家常**：不聊工作/柴米油盐，停留在逻辑层无法产生情绪波动
3. **只聊你们之间的事情**：聊感情经历、暧昧话题，创造情绪和性拉力
4. **表情能帮大忙**：表情调节语意，表达真实情感，让她感觉你是活生生的人
5. **像幼儿园小孩一样对话**：直白、不加修饰、用情绪而非逻辑沟通
6. **不要在不见面的情况下升级关系**：精神联结必须配以身体接触才能完成
7. **见好就收**：在情绪最高点终止对话，制造期待，不要把话题聊尽
8. **注意间隔和时间**：每条至少间隔10分钟，了解她的作息时间

## A1 — 书中案例

**反面案例**：
- "吃饭了没？""在干吗？""今天忙不忙？"——这些开启话题的方式非常糟糕
- 在微信上表白或询问感觉 → 悲剧前奏，见光死

**正面案例**：
- 在最火热的时候频繁回复，然后突然消失
- 用表情调节语意："白痴" vs "白痴-_-"

## A2 — 触发场景与语言信号

**触发场景**：
- 刚认识需要维持联系感
- 约会后需要保持温度
- 需要邀约前的沟通铺垫

**语言信号**：
- 正面信号：她回复很快、用语音、主动延续话题
- 负面信号：回复很慢、很敷衍、用词简短

**响应法则**：
- 她热情 → 可以多聊几句，但仍要见好就收
- 她冷淡 → 等一两天再重新开启话题，不要追问

## E — 可执行步骤

1. **开场执行**：
   - 用陈述代替提问："今天在三里屯看到一家很棒的甜品店"
   - 用表情增加趣味："[得意][得意]"
   - 避免："你在干嘛？""吃了吗？"

2. **对话中执行**：
   - 聊你们之间的事：共同经历、感情观、暧昧话题
   - 像幼儿园小孩：不加修饰、直白、情绪化
   - 每条间隔10分钟，不要秒回

3. **结束执行**：
   - 在情绪最高点主动终止
   - 用有趣的理由离开："我要去开会，回头聊"
   - 留下悬念，让她期待下次对话

4. **邀约执行**：
   - 电话邀约前先有聊天电话建立舒适感
   - 用逆向邀约法："全北京都在传你晚上要去三里屯"
   - 不要直接问"你什么时候有空"

## B — 边界

- **适用边界**：18-35岁男性，适用于中国城市社交软件沟通
- **理论边界**：基于进化心理学"情绪vs逻辑"理论，逻辑层对话无法产生吸引
- **情境边界**：适合刚认识阶段；长期关系中需要平衡逻辑与情绪沟通
- **危险边界**：永远不要在没见面的情况下表白或要求确认关系
- **伦理边界**：目的是建立真实联系，不是玩弄话术
