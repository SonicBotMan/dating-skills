# Skill 12: social-display-optimization — 社交展示面优化

## R — 原文引用（≤150字）

> "精选出自己的十张照片，分别是：●你和不同朋友在一起开心玩乐，展现你有女人缘的一面；●自己运动时的照片两张，展现生活情趣；●展示自己的书画作品或者演奏乐器的照片；●自己照得最好看的生活照；●自己在旅行时拍的照片。一共只需要十张图，因为非好友只能看到十张照片，放多了没用。"

## I — 骨架（5-15行）

1. **头像设置**：
   - 本人半身清晰照，展示最好看的轮廓
   - 背景弱化，不要喧宾夺主
   - 避免卡通头像、证件照式自拍、戴墨镜室内照

2. **十张照片原则**：
   - 朋友聚会照（预选+社交认证）
   - 运动照片两张（生活情趣）
   - 才艺照片（书画/乐器）
   - 最好看的生活照
   - 旅行照片

3. **禁止内容**：
   - 颓废照片+抄袭文字
   - 晒方向盘/金表（炫富照）
   - "到此一游"摆拍
   - 屋子里戴墨镜自拍

4. **昵称与资料**：
   - 昵称不超过四个字
   - 避免伤春悲秋、无病呻吟
   - 地区填真实生活地

## A1 — 书中案例

**好照片示例**：
- 和朋友聚会：良好社交认证，正能量友善
- 展示厨艺：西式开放式厨房，会厨艺是高生活价值
- 与小动物/小孩合照：爱心、保护欲
- 运动/健身照：展现健康生活

**坏照片示例**：
- 颓废自拍配非主流文字
- 方向盘+金表炫富（像暴发户）
- 景点标志性拍照（无个人特色）

## A2 — 触发场景与语言信号

**触发场景**：
- 社交软件（微信/陌陌/探探）形象建设
- 相亲网站资料优化
- 形象展示需要系统性提升

**照片质量判断**：
- 给几个女生看，都说"好看得不像本人"就对了
- 照片能展示你的生活方式和内在品质
- 非好友只能看到十张，精选比堆砌重要

**价值展示优先级**：
1. 社交认证（朋友合照、预选）
2. 生活情趣（运动、才艺）
3. 正面情绪（开心、有活力）
4. 生活品质（旅行、品质场所）

## E — 可执行步骤

1. **头像优化**：
   - 拍摄有角度的半身照，展示最好看的轮廓
   - 背景简洁，弱化背景
   - 让女性朋友评价，选择她们认为最好看的

2. **相册建设**：
   - 整理现有照片，删掉不合格的
   - 补拍缺失类型：运动照、聚会照、旅行照
   - 总数控制在十张以内

3. **资料完善**：
   - 昵称简洁（≤4字），与本人相关
   - 地区填真实生活地
   - 个人签名避免无病呻吟

4. **动态维护**：
   - 定期发布高质量生活动态
   - 避免刷屏或过于频繁
   - 保持正面积极的形象

## B — 边界

- **适用边界**：18-35岁男性，适用于中国城市社交媒体环境
- **理论边界**：基于"社交认证"和"预选"理论，照片是产生第一印象的重要渠道
- **情境边界**：主要用于网络认识阶段；线下见面后需要真人匹配
- **危险边界**：不要过度包装或欺骗，照片与本人差距太大会造成"见光死"
- **伦理边界**：展示真实生活状态，不是伪造人设
