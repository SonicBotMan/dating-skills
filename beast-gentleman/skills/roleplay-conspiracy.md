# Skill 17: roleplay-conspiracy — 角色扮演/共谋

## R — 原文引用（≤150字）

> "角色扮演可以让你和约会对象进入一个更有趣的互动模式……角色扮演可以建立起一个只有你和她存在的世界，旁人无法参与。这会让你们的关系更有黏性，你们的交集会更多，情绪也会更同步。共谋必须是建立在有趣的互动上的。假设你和她一起对抗其他人或者与外面的世界战斗。一些只有你们两人知道的小秘密就足够形成共谋。"

## I — 骨架（5-15行）

### 角色扮演
- 让女性扮演相关联的角色（老师学生/医生护士/父女等）
- 你设定对自己有利的角色框架
- 双方在角色框架中展开互动
- 建立只有你和她存在的"共谋"世界

### 共谋建立方式
- 引用她的"哏"（引以为豪的事）
- 使用她常用的词汇（口头禅）
- 只有你们懂的小笑话
- 共同观察他人、编故事

### 使用时机
- 必须在女性对你有兴趣后使用
- 如果对方不进入角色 → 不要在意，继续建立吸引
- 不能强行让不感兴趣的人入戏

### 角色扮演示例
- 老师和学生："我要罚你晚点留下来抄作业"
- 宠物店："如果你是小狗，我希望你是泰迪，我就会带你回家"

## A1 — 书中案例

**案例：老师与学生**
男："我看你是今天班上最调皮的那个女生。我要罚你晚点留下来抄作业。"（坏笑）
女："不要啊老师！妈妈今天做了饭，我要赶回家吃饭啊。"（套入角色）
→ 角色扮演成功，双方情绪同步

**案例：宠物店**
男："如果你是小狗的话，你希望变成哪一种？"
女："泰迪，我特别喜欢泰迪。"
男："哇，如果我在宠物店里看见你，一定会带你回家。"（笑）
女："哈哈，神经病。"（笑）
→ 角色扮演成功过渡到牵手

**共谋建立示例**：
- 聚餐时用脚轻轻勾她的高跟鞋
- 酒吧互动好后一起偷偷甩掉朋友
- 和她一起观察别人，给他们编故事
- 引用她引以为豪的事："你能带30多个小学生安全出房间，对你来说肯定没问题"

## A2 — 触发场景与语言信号

**触发场景**：
- 约会中需要增加趣味性
- 双方有一定吸引基础
- 需要加深情感联结

**角色扮演信号**：
- 她对你笑、情绪积极
- 她主动延续话题
- 她愿意配合你的互动

**不配合信号**：
- 她表现得冷淡或不耐烦
- 她不进入你设定的角色
- 她对你的话没有回应

**共谋检测**：
- 她使用你教她的词汇
- 她记得只有你们知道的小秘密
- 她主动提起之前的"梗"

## E — 可执行步骤

1. **角色扮演准备**：
   - 预设几个你擅长的角色（老师、学生、医生等）
   - 角色设定要对自己有利
   - 确保对方能轻松进入角色

2. **角色扮演执行**：
   - 打闹时顺势描述对方是某种角色
   - 对方接受 → 进入角色互动
   - 对方不接受 → 轻松跳过，不强求

3. **共谋建立执行**：
   - 留意她引以为豪的事 → 之后引用
   - 留意她的口头禅 → 之后重复使用
   - 建立只有你们懂的小笑话
   - 共同经历小"阴谋"（如偷偷溜走）

4. **深化联结**：
   - 在后续互动中引用共谋内容
   - 强化"只有你们懂"的特殊感
   - 用共谋内容化解尴尬或拉近距离

## B — 边界

- **适用边界**：18-35岁男性，适用于约会和日常联系
- **理论边界**：共谋是建立联系感的技巧，角色扮演是共谋的形式之一
- **情境边界**：需要先有足够吸引；没有吸引时强行角色扮演会被拒绝
- **危险边界**：不要对不感兴趣的人使用；不要让角色扮演变成控制手段
- **伦理边界**：角色扮演是为了增加趣味和联结，不是欺骗
