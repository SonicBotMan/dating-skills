- **书名**：影响力（经典版）

- **出版**：1984（2006全新修订版）
- **字数**：约181,528字
- **主题**：六大影响力原则及其应用

## 学习路径

### 路径A：商业应用（销售/营销/运营）

```
1. reciprocity-principle（建立基础关系）
   ↓
2. scarcity-principle（制造紧迫感）
   ↓
3. social-proof（增加信任背书）
   ↓
4. liking-principle（建立喜好）
   ↓
5. authority-principle（强化专业感）
   ↓
6. commitment-consistency（锁定长期客户）
```

### 路径B：人际影响力（社交/领导力）

```
1. liking-principle（建立喜好）
   ↓
2. reciprocity-principle（制造亏欠感）
   ↓
3. commitment-consistency（获得承诺）
   ↓
4. social-proof（借用群体压力）
   ↓
5. authority-principle（建立领导力）
   ↓
6. scarcity-principle（提升价值感）
```

### 路径C：自我防御（反操控）

```
1. 识别互惠式让步 → 区分交易与关系
   ↓
2. 识别承诺一致性操控 → 区分真实认同与被迫服从
   ↓
3. 识别虚假社会认同 → 独立判断
   ↓
4. 识别喜好转移 → 把人和产品分开
   ↓
5. 识别权威符号 → 质疑权威资格
   ↓
6. 识别稀缺话术 → 区分想要与需要
```

## 原则组合矩阵

| 组合 | 效果 | 典型应用 |
|------|------|---------|
| 互惠 + 承诺 | 内化认同 | 特百惠销售、会议征集签名 |
| 互惠 + 稀缺 | 紧迫+恩惠 | "最后机会+额外赠送" |
| 社会认同 + 稀缺 | 竞争+稀缺 | "众人争抢" |
| 喜好 + 权威 | 专业+亲和 | 专家推荐产品 |
| 承诺 + 稀缺 | 锁定+紧迫 | 限时优惠 |
| 社会认同 + 喜好 | 从众+好感 | 明星代言+用户评价 |
