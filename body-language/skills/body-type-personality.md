# body-type-personality

## Definition
体质类型分析是通过观察人体的结构、骨骼、肌肉、脂肪分布来判断一个人的基本性格倾向和天赋才能。这是九种形体特征中最重要的系统性特征，分为智慧型、好动型、活力型三大类。

## RIA++ 六段

### R 学 (Rule/Principle)
三种体质类型各有明确的外形特征和性格倾向：

**智慧型（思想家型）**
- 外形：头大、前额高宽、脸小、鼻细、下巴突出、体质文弱、肩削斜、手指细长、嗓音高尖
- 积极面：智力高、聪明、善推理、富创造力
- 消极面：体质弱、懒惰、缺活力
- 适宜职业：需要思考、设计、研究的工作

**好动型（实干家型）**
- 外形：方形嘴巴、方形前额、颧骨突出、高鼻梁、嗓音深沉、肌肉骨骼显露、肩宽方、手方形
- 积极面：独立、精力充足、喜户外、自由、勤奋
- 消极面：智力不集中、不喜读书
- 适宜职业：运输、建筑、探险、机械、体育、销售

**活力型（管理者型）**
- 外形：圆脸、两颊丰满、宽鼻孔、下巴肥或双下巴、圆身躯、手掌肥厚
- 积极面：擅管理、行政、理财力佳、好吃、活动力足
- 消极面：太喜享乐、懒惰
- 适宜职业：商业、金融、政治、管理

### I 例 (Instance - Success)
一位电梯司机接受个性分析后，按照作者建议从静态工作转向"制作大件物品"的行业。他原本是钟表匠，因眼睛问题失业。在接受分析后，他开始制作家具，后来专门开设木器店，收入比当电梯司机时增加了一倍。他的体质特征显示他适合动手制作类工作，而不是重复性的操作类工作。

### I 例 (Instance - Failure)
许多智慧型的人被强迫去做体力劳动，导致郁郁寡欢、愤世嫉俗。作者举例：一位本该做研究的智慧型青年被父亲安排去当建筑工人，他每天都在痛苦中度过，绩效极差，最后患上了严重的抑郁症。让他读书、做计划、发展智力才是正道。

### A+ 析 (Analysis - Why Success)
成功原因：准确识别了他的好动型体质与动手天赋的结合点。钟表匠的背景说明他有一定的精细动作能力，而电梯司机的重复性工作无法发挥这一优势。转向家具制作，既满足了动手的需求，又能让他看到成果。

### A+ 析 (Analysis - Why Failure)
失败原因：将智慧型的人强制安排到体力劳动岗位，是"逆天而行"。智慧型的大脑需要刺激和挑战，重复性的体力工作对他们来说是折磨。根源是社会偏见——认为"劳力者治于人"，忽视了不同体质适合不同工作的自然规律。

### A 艺 (Art/Technique)
体质类型识别速查：

**智慧型识别清单**
- [ ] 头大、前额高宽
- [ ] 脸小、鼻细
- [ ] 下巴突出
- [ ] 体质文弱
- [ ] 肩削斜
- [ ] 手指细长
- [ ] 嗓音高而尖
- [ ] 脸形如倒三角或梨形

**好动型识别清单**
- [ ] 方形嘴巴
- [ ] 方形前额上端
- [ ] 颧骨突出
- [ ] 高鼻梁
- [ ] 嗓音深沉
- [ ] 肌肉骨骼显露
- [ ] 肩宽而方
- [ ] 手方形

**活力型识别清单**
- [ ] 圆脸
- [ ] 两颊丰满
- [ ] 宽鼻孔
- [ ] 下巴肥或双下巴
- [ ] 圆身躯
- [ ] 手掌肥厚

**组织特征（粗/细）附加判断**
- 粗肌肤+粗相貌：爽直、魄力、有精神 → 适合力量型工作
- 细肌肤+细相貌：爱美、富理想、敏感 → 适合美巧型工作

**紧韧特征附加判断**
- 柔软易屈：易感动、多才艺，但缺乏力量
- 富韧力：乐观、顺应、热诚、有力，但易变
- 干硬：坚决、意志力强、经济、勤奋，但易固执
