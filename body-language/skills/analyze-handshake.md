# analyze-handshake

## Definition
握手分析是通过感受对方手的力量、温度、湿度和握法来判断其性格、情绪状态和交往态度。这是在社交场合快速判断他人的有效技巧，也是"表现"特征中最直接的观察点。

## RIA++ 六段

### R 学 (Rule/Principle)
握手时的肌肉松紧和骨骼软硬反映性格：
- **柔软易屈的手** = 柔和顺从、多愁善感
- **富韧力的手** = 乐观进取、适应力强
- **干硬的手** = 坚决意志、固执倔强

手的温度和湿度也传递情绪信息：温暖=友善热情，冰凉=冷淡或紧张，潮湿=焦虑。

### I 例 (Instance - Success)
在一次 networking 活动中，我与三位陌生人握手后快速判断：
- 第一位：握手温暖有力、拇指压紧 → 友善诚恳 → 深入交谈
- 第二位：握手松软无力、手指冰凉 → 消极冷淡 → 保持礼貌距离
- 第三位：握手用力过度、手掌潮湿 → 紧张焦虑 → 给予安抚和引导

结果活动结束时三位都对我留下了好印象。

### I 例 (Instance - Failure)
一次面试中，我判断应聘者握手"有力但唐突"，认为他自信且有魄力，于是给了高分。但入职后发现他难以与团队协作——他的握手过于用力实际上反映了他在掩饰内心的紧张和缺乏安全感。

### A+ 析 (Analysis - Why Success)
成功原因：建立了"握手=性格+情绪"的双重判断框架。温暖=友善、用力=诚恳、冷淡=疏离。关键是将握手的感觉与当时情境结合分析，就像中医的"望闻问切"——不能只凭单一症状下诊断。

### A+ 析 (Analysis - Why Failure)
失败原因：把"用力"等同于"自信"是一个过于简单化的判断。面试情境中的握手可能受到多种因素影响：紧张、刻意表现、甚至前一天的情绪状态。手的温度、节奏、眼神配合都应该纳入判断。

### A 艺 (Art/Technique)
握手分析 Checklist：

**1. 力量判断**
- 有力+拇指压紧 = 友善诚恳
- 软弱无力 = 缺乏热情
- 过于用力 = 可能掩饰不安全感

**2. 温度感知**
- 手掌温暖 = 性格温暖
- 手掌冰凉 = 冷淡或紧张

**3. 湿度观察**
- 潮湿 = 紧张焦虑
- 干燥 = 镇定

**4. 节奏感知**
- 来回摇动2-3次 = 正常社交
- 瞬间即松 = 敷衍
- 紧握不放 = 控制欲强

**5. 综合判断禁忌**
- 不能只凭握手判断性格
- 要结合眼神、表情、情境
- 亲密关系中的握手与社交握手意义不同
